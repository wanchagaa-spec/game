# เช็คลิสต์ทดสอบ Studio — 5E-1b แถวเดียวแบบ Age of War

> ⚠️ **ห้าม merge จนกว่าผู้ใช้สั่ง** · ดีไซน์เต็ม + ตารางต่อด่าน: `docs/data-schema.md` §7.13 · คำสั่ง debug: `docs/debug-commands.md`
> รอบนี้เป็น**ตรรกะฝั่ง server + ภาพชั่วคราว** (คนบล็อก ๆ + กล่อง) · โมเดลลูก/ภาพจริงทำ 5E-2
> 5E-1b แทนสนาม 6 ช่อง + รวมพลของ 5E-1 ทั้งหมด (เช็คลิสต์ 5E-1 เดิมไม่ต้องไล่แล้ว)
> คำสั่ง debug เรียกผ่านสะพานเสมอ: `game.ServerStorage.EggServiceDebug:Invoke("debugX", game.Players:GetPlayers()[1], ...)`

## 0. เตรียม

- [ ] เข้าเกมใน Studio (Play) · มีแม่ในคอก (ผลิตลูก) อย่างน้อย 2 ตัวละคร (กองลูก ≥ 2 กอง) + แม่ในกระเป๋าอย่างน้อย 2 ตัว (`debugGrantMother` ได้)
- [ ] ผ่านด่าน 1 แล้ว (เปิดอัญเชิญครั้งแรก = ด่าน 1 พังทันที ไม่ต้องมีทหาร) · ด่านที่กำลังตี = ด่าน 2
- [ ] ถ้าอยากได้ลูกเร็ว: รอคลังสะสม หรือ `debugGrantMother` แม่หนักหลายตัวเข้าคอก

## 1. หน้าต่างอัญเชิญ — เลขลำดับร่วมสองแท็บ

- [ ] เปิดแท่นอัญเชิญ (E ค้าง) ครั้งแรก (ยังไม่เคยติ๊ก) → แท็บลูก**ติ๊กทุกกองไว้ก่อน** เรียงพลังต่อตัวมาก → น้อย (เลข 1, 2, …)
- [ ] ไปแท็บแม่ ติ๊กแม่ตัวหนึ่ง → ได้**เลขต่อจากกองลูก** (เช่นมีลูก 2 กอง → แม่ได้ 3) ไม่ใช่เริ่ม 1 ใหม่
- [ ] เอาติ๊กกองลูกเลข 1 ออก → เลข**ทั้งสองแท็บ**เลื่อนขึ้น (แม่ 3 → 2)
- [ ] ใต้รายการมีบรรทัด **"ลำดับ: หมู → ม้า → แม่ลิง → วนกลับตัวแรก"** ตรงกับเลขที่ติ๊ก · ไม่ติ๊กอะไร = "ลำดับ: (ยังไม่ได้ติ๊ก)" + ปุ่มส่งปิด
- [ ] ส่งไปรบ → กล่องยืนยันข้อความเดิม (แม่อาจตายถาวร + ตายหมดตอนด่านพัง) → ยืนยัน
- [ ] ปิดหน้าต่างแล้วเปิดใหม่ → แม่ที่ส่งไปแล้วอยู่บนสุดป้าย "ในสนาม" **มีเลขลำดับตรงตำแหน่งเดิม** · กดเอาติ๊กออกไม่ได้
- [ ] ติ๊กแม่ในกระเป๋าไว้แต่ปิดหน้าต่างโดยไม่ส่ง → เปิดใหม่ติ๊กหายไป (ไม่จำ)
- [ ] หัวหน้าต่างขึ้น **"แถว N/10"** ระหว่างอัญเชิญ · ไม่มีคำว่า "กำลังรวมพล" ที่ไหนเลย

## 2. สองแถวเดินเข้าหากัน

- [ ] ฝั่งเรา**โผล่ที่แท่นอัญเชิญ**ทีละตัว ต่อแถวเดียวยาวไปทางแท่น (ลูกเขียว · แม่เหลืองใหญ่กว่าเล็กน้อย) · **ไม่เกิน 10 ตัว**
- [ ] ฝั่งศัตรู (แดง) เป็นแถวเดียวยาวไปทางกำแพง ≤ 10 ตัว · ลำดับ **เล็ก 5 → ใหญ่ 1 → เล็ก 5 …** · ตัวใหญ่ใหญ่กว่าชัดเจน
- [ ] ระยะห่างในแถวเท่า ๆ กัน (ตัวใหญ่เว้นมากกว่านิดหน่อย) · ไม่ซ้อนกัน
- [ ] สองแถว**เจอกันกึ่งกลาง**ระหว่างแท่นกับกำแพง (ด่าน 2 เดิน ~2 วิ) · HUD กลางบน "🚶 เดินทัพไปเจอศัตรู" ระหว่างเดิน
- [ ] ระหว่างเดิน + ตอนสู้กึ่งกลาง **ป้อมไม่ยิง** (ไม่มีเส้นส้ม) · หลอดศัตรูไม่ลดระหว่างเดิน
- [ ] **ตีกันเฉพาะตัวหน้าสุด** — แถบเลือดลดแค่ตัวหน้าสุดของสองฝั่ง ตัวอื่นเต็มหลอด
- [ ] ทุกตัวมีแถบเลือดเหนือหัว · เดินออกไกล ๆ แถบไม่ขยายตามจอ (ขนาดเป็น studs)

## 3. หน้าสุดตาย → แถวขยับ + ต่อท้ายตามรอบวน

- [ ] ตัวหน้าสุดของเราตาย → เอฟเฟกต์ตาย · **ทั้งแถวเดินขยับขึ้น**ลื่น ๆ (ไม่วาร์ป) · ตัวใหม่ต่อท้ายแถว
- [ ] ศัตรูหน้าสุดตาย → แถวศัตรูขยับขึ้น · ตัวถัดไปในลำดับโผล่ท้ายแถว
- [ ] `debugBattleStatus` → "แถวเรา (n/10 · หน้าสุดก่อน)" ลำดับชนิด/เลือด · "รอบวน" มี **▶** ชี้ตัวถัดไป · ลำดับที่ปล่อยจริงวน 1, 2, …, N, 1, 2, …
- [ ] กองที่หมด → ถูกข้ามในรอบวน (ไม่ค้าง ไม่มีช่องว่างในแถว)
- [ ] แม่ออกได้**ครั้งเดียว** — วนกลับมาถึงแม่ที่ยังอยู่ในแถว = ข้าม ไปรายการถัดไป
- [ ] แม่โดนฆ่า → toast **"แม่ตายในสนามรบ 1 ตัว (ตายถาวร)"** · หายจาก roster ("แม่ในสนามรบ X/10" ลด) · รอบวนข้ามแม่ตัวนั้นตลอดไป
- [ ] ทุกรายการในรอบวนหมด (ลูกทุกกองที่ติ๊กหมด + แม่อยู่ในแถว/ตายหมด) → หยุดปล่อย ตัวที่อยู่ในแถวสู้ต่อจนตาย ·
      แม่ในคอกผลิตลูกเพิ่ม → ปล่อยต่อเอง

## 4. ศัตรู · กำแพง · ป้อม

- [ ] หลอดกลางบน: **"ศัตรูเหลือ N ตัว · xx%"** ลดลงเรื่อย ๆ · **"กำแพง N HP · 100%"** ไม่ลดเลยตอนศัตรูยังเหลือ
- [ ] ศัตรูหมด → แถวเรา**เดินจากกึ่งกลางไปชิดกำแพง** (HUD "🚶 เดินทัพไปกำแพง") · ระหว่างเดินกำแพงยังไม่ลด · ถึงแล้ว**ตัวหน้าสุด**ตีกำแพง (ตัวอื่นต่อคิว)
- [ ] **ป้อม** = กล่องเทาบนสันกำแพงด่านที่กำลังตี (มีตลอด) · **ยิงเฉพาะตอนแถวเราเดินถึงกำแพงแล้ว** — เส้นยิงสีส้มไปที่**ตัวหน้าสุด** ~ทุก 1 วิ
- [ ] ด่านที่ศัตรูหมดแล้ว (`debugSetStageProgress(player, N, 0, …)`) → ปล่อยแล้วเดินจากแท่น**ถึงกำแพงเลย** (ด่าน 9 ~44 วิ) · ป้อมเริ่มยิงหลังเดินถึง
- [ ] `debugTurret(false)` → ป้อม + เส้นยิงหาย · `debugBattleStatus` บอก "ป้อม ปิด (debug)" · `debugTurret(true)` → กลับมา
- [ ] เลขดาเมจลอยเหนือหน้ากำแพง (ของเดิม 3B-2) ยังขึ้นตอน HP ศัตรู/กำแพงลด

## 5. กำแพงพัง

- [ ] เหลือกำแพงน้อย ๆ (`debugSetStageProgress(player, 2, 0, 1)`) + มีทหาร → กำแพงพัง
- [ ] popup ผ่านด่านเหมือนเดิม (ไข่รางวัล + จำนวนแม่ที่ตายตอนด่านพัง)
- [ ] แม่ที่เหลือใน roster **ตายหมด** (กติกาเดิม) · ลูกที่รอดในแถว**กลับเข้ากอง** (จำนวนในกองไม่หาย)
- [ ] บอสห้องนั้นยังอยู่ → ติดล็อกอัญเชิญเหมือนเดิม · แถวเราหายทันที (กลับกอง)

## 6. หยุดอัญเชิญ · ศัตรูบาดเจ็บ · ออกเกม

- [ ] สู้จนศัตรูหน้าสุดเลือดลด → กด "หยุดอัญเชิญ" → แถวเราหาย (ไม่มีเอฟเฟกต์ตาย = กลับกอง) · **ศัตรูหน้าสุดยังยืนกึ่งกลาง แถบเลือดเท่าเดิม**
- [ ] เปิดอัญเชิญอีกครั้ง → แถวเราเดินจากแท่นมาใหม่ · ศัตรูยืนรอที่กึ่งกลาง (ไม่เดินกลับ) · ตีต่อจากเลือดเดิม · แม่ที่รอดออกได้อีกรอบ
- [ ] ออกเกมแล้วเข้าใหม่ → HP ทหารฝ่ายรับที่เหลือ (หลอด %) เท่าเดิม · แถวศัตรูสร้างใหม่ (แผลอยู่ตัวหน้าสุด)
- [ ] เข้าใหม่แล้วเปิดหน้าต่างอัญเชิญ → แม่ใน roster **ไปต่อท้ายรอบวน** (ตำแหน่งเดิมจำแค่ใน memory · ยอมรับแล้ว) · จัดใหม่แล้วส่ง = ใช้ลำดับใหม่

## 7. auto-pause

- [ ] ใช้งานปกติไม่ควรเกิดเลย (ทหารมีดาเมจเสมอ) — ถ้าเห็นคำเตือน "ตีไม่เข้า — หยุดปล่อยอัตโนมัติ" ระหว่างเล่นปกติ = บั๊ก แจ้งด้วย

## 8. ประสิทธิภาพ

- [ ] บนจอมีทหาร + ศัตรูไม่เกิน 20 ตัว + ป้อม 1 (Explorer: `Workspace.LocalTroops`)
- [ ] ผู้เล่น 2 คนตีคนละด่าน → แต่ละคนเห็นแค่แถวของตัวเอง
- [ ] ไม่มี warn "[CombatService] เหตุการณ์เกิน" / "[Main] TroopRenderer.updateFromPayload ล้มเหลว" ใน Output
