## 0. เตรียมก่อนเริ่ม

1. `rojo serve` → Studio เชื่อม Rojo → กด **Play**
2. Command Bar ฝั่ง **Server** (Test → Current: Server) · คำสั่งบอสเรียกผ่านสะพานเดียวกับของเดิม:

```lua
-- ข้ามเวลา (ไม่ต้องรอ 9 นาที)
game.ServerStorage.EggServiceDebug:Invoke("debugBossNight")   -- ต้นกลางคืนทันที
game.ServerStorage.EggServiceDebug:Invoke("debugBossDay")     -- ต้นกลางวันทันที
print(game.ServerStorage.EggServiceDebug:Invoke("debugBossStatus"))
-- ตีบอส/ฆ่าบอสในนามผู้เล่นคนแรก (ต้องเป็นกลางวัน + มีบอส)
game.ServerStorage.EggServiceDebug:Invoke("debugDamageBoss", game.Players:GetPlayers()[1], 300)
game.ServerStorage.EggServiceDebug:Invoke("debugKillBoss", game.Players:GetPlayers()[1])
```

3. เตรียมลูกให้ปล่อยได้: มีแม่ในคอก 1–2 ตัว (🐾 → "สวมใส่ที่ดีที่สุด") แล้วรอผลิตสักพัก
4. ข้อที่มี 👥 = ทดสอบสองเครื่อง (Test → Clients and Servers → 2 Players)
5. ดู Output ฝั่ง server: ทุกครั้งที่ phase เปลี่ยน/บอสตายจะมีบรรทัด `[BossService] ...` สรุปสถานะ

## 2. กลางคืน — วาป · กำแพงกั้น · ตัวเลขนับถอยหลัง · บอสเกิด

- [ ] `debugBossNight` → **วาปทุกคน**มาหน้าป้อม **ฝั่งลานกลาง** (หน้าแท่นอัญเชิญ ไม่ใช่ในเลน) ไม่ว่าจะยืนอยู่ที่คอก/ร้าน/ลึกในเลน
- [ ] 👥 สองคนวาปมาคนละจุด **ไม่ซ้อนกัน** · หันหน้าเข้ากำแพงกั้น (+X) · ไม่ยืนทับแท่นอัญเชิญ/ป้ายดาเมจ · ตอนรอ **ไม่มีปุ่ม E ของแท่นเด้งขึ้น**
- [ ] (5B) กำแพงกั้น**สีขาวทึบ**ปิดช่องทางเข้าเลน**พอดี** — ต่อกับกำแพงหินสองข้างเป็นแนวเดียว ไม่มีช่องว่าง ไม่ยื่นออกมา สูงเท่ากำแพงหิน
- [ ] **เดินชนกำแพงกั้นแล้วผ่านไม่ได้** · กระโดดข้ามไม่ได้ · วิ่งเร็วสุดก็ไม่ทะลุ · ขอบซ้าย/ขวาไม่มีช่องให้ลอด
- [ ] (5B) รอยต่อกำแพงกั้นกับกำแพงหินข้าง ๆ และกับกำแพงข้างเลน **ไม่กระพริบ** (ดูจากหลายมุมกล้อง ทั้งหน้า/หลัง/ด้านบน)
- [ ] ตัวเลขใหญ่**สีแดงเข้ม**บนหน้ากำแพงกั้น (ฝั่งลาน) **59 → 58 → … → 0** เลขละ 1 วินาที · อ่านชัดจากหน้าป้อม · คำบรรยายสีเข้มอ่านออกบนพื้นขาว
- [ ] 👥 สองเครื่องเห็น**เลขเดียวกัน**ในเวลาเดียวกัน
- [ ] บอส (กล่องม่วง ตาเหลืองหันไปทางปากเลน) **เกิดมุมขวาของห้องบอสด่าน 1** (ฝั่ง +Z) · แถบ HP เหนือหัวเต็ม `บอส 1,000 / 1,000`
- [ ] toast "🌙 กลางคืนแล้ว — บอสตื่นที่ห้องบอสด่าน 1 …" ขึ้นทุกคน
- [ ] ระหว่างกลางคืนเดินไปคอก/ร้าน/แท่นอัญเชิญได้ตามปกติ · **กด E ค้างที่แท่นอัญเชิญได้** (กำแพงกั้นไม่บังแท่น)
- [ ] ทหารที่อัญเชิญอยู่ (ถ้ามี) **ยังเดินผ่านกำแพงกั้น/บอสไปตามปกติ** (เป็นภาพ ไม่ชน) · HP ด่านที่กำลังตียังลดตามปกติ
- [ ] 👥 อีกคน**เข้าเกมระหว่างกลางคืน** → เกิดที่คอกตามปกติ ไม่ถูกวาป
- [ ] Reset ตัวละครระหว่างกลางคืน (Esc → Reset) → เกิดที่คอกตามปกติ ไม่ถูกวาป

## 3. เช้า — เข้าไปตีบอส

- [ ] เลขถึง 0 → **กำแพงกั้นหายไป** (มองไม่เห็น + เดินผ่านได้) · ตัวเลขหายไปด้วย · **ไม่มีการวาปกลับ**
- [ ] (5B) เดินผ่านปากเลนเข้าไป (ห้องด่าน 1 เริ่มตรงช่องประตู) → **อาวุธ (แท่งเงิน) ขึ้นมือเอง** · ถอยกลับเข้าลาน → อาวุธถูกเก็บเอง
- [ ] ยืนชิดบอสแล้วคลิก → แถบ HP ลด **ครั้งละ 10** (อาวุธขั้น 1) · คลิกรัวเร็วกว่า 0.5 วิ ไม่ลดเกินจังหวะ
- [ ] ยืนไกลบอสเกินระยะ (~14 studs จากกึ่งกลาง) แล้วคลิก → HP **ไม่ลด**
- [ ] มือถือ (Device Emulator): แตะจอตอนถืออาวุธ = ตี
- [ ] 👥 สองคนตีพร้อมกัน → ทั้งสองเครื่องเห็น HP **ค่าเดียวกัน**
- [ ] `debugBossStatus` → "ผู้ทำดาเมจ" มี UserId ของทั้งสองคนพร้อมดาเมจที่ทำไปจริง (เรียงมาก → น้อย)
- [ ] ตีจน HP หมด (หรือ `debugKillBoss`) → บอสหายไป · toast **"กำจัดบอสแล้ว!"** ขึ้นทุกคน · อาวุธถูกเก็บ
- [ ] (5B) บอสตายแล้ว **ได้เงินบอส** (ดู §10) · Output มีรายชื่อผู้ทำดาเมจ + บรรทัด `[BossService] เงินบอส …`
- [ ] ตายแล้ว**ไม่เกิดใหม่จนคืนถัดไป** · `debugBossNight` → เกิดใหม่ HP เต็ม
- [ ] บอสตีกลับ: **ปิดอยู่** (`BOSS_ATTACK_ENABLED = false`) — ยืนชิดบอสนาน ๆ HP ผู้เล่นไม่ลด

## 4. บอสไม่ตายข้ามคืน

- [ ] กลางวันตีบอสไปบางส่วน (`debugDamageBoss` 300 → HP 700) → `debugBossNight`
      → บอส**ฟื้น HP เต็ม 1,000** (ตัวเดิม ไม่ได้หายแล้วโผล่) · `debugBossStatus` บันทึกผู้ทำดาเมจเริ่มนับใหม่

## 5. ล็อกอัญเชิญ — พังกำแพงขณะบอสยังอยู่

เตรียม (ผู้เล่นคนแรก):
```lua
game.ServerStorage.EggServiceDebug:Invoke("debugBossNight")
game.ServerStorage.EggServiceDebug:Invoke("debugBossDay")      -- บอสอยู่ กลางวัน
game.ServerStorage.EggServiceDebug:Invoke("debugSetStageProgress", game.Players:GetPlayers()[1], 1, 0, 0)
game.ServerStorage.EggServiceDebug:Invoke("debugSetStageProgress", game.Players:GetPlayers()[1], 2, 0, 1)  -- ด่าน 2 เหลือกำแพง HP 1
```

- [ ] ไปแท่นอัญเชิญ → กด E ค้าง → ติ๊กกองลูก → "ส่งไปรบ" → ทหารออก → กำแพงด่าน 2 พังภายใน ~1 วิ
- [ ] ทันทีที่พัง: **ทหารหยุด** (ไม่มีทหารตัวใหม่ออก · HUD การรบหาย) · toast "🔒 พังกำแพงแล้วแต่บอสยังอยู่ — กำจัดบอสก่อนจึงจะอัญเชิญต่อได้"
- [ ] popup ผ่านด่าน 2 (ไข่รางวัล 4A · แม่ใน roster ตาย ถ้ามี) **ยังขึ้นตามปกติ** — ล็อกไม่ได้กินรางวัล
- [ ] กด E ค้างที่แท่น → **แค่เปิดหน้าต่าง** ไม่เริ่มอัญเชิญเอง
- [ ] ในหน้าต่าง: ปุ่มส่งเป็น "🔒 ส่งไปรบไม่ได้ — กำจัดบอสก่อน" **กดไม่ได้** · หัวหน้าต่างมี ⚠️ "กำจัดบอสก่อนจึงจะอัญเชิญต่อได้"
- [ ] แท็บแม่: ติ๊กแม่ไม่ได้ (ทาเทา) · ข้อความล็อก**ขึ้นครั้งเดียว** ไม่ซ้ำสองรอบ
- [ ] 👥 อีกคนที่**ไม่ได้**พังกำแพงตอนนี้ → อัญเชิญได้ตามปกติ (ล็อกเฉพาะคนที่พัง)
- [ ] 👥 ผู้เล่นใหม่ (ด่าน 1 ไม่มีกำแพง) กดส่งไปรบครั้งแรกตอนบอสอยู่ → **ไม่ติดล็อก** (ด่าน 1 "พัง" ฟรี ไม่นับ)
- [ ] ออกเกมแล้วเข้า**เซิร์ฟเดิม**ใหม่ (ถ้าทำได้ใน Studio) → **ยังติดล็อก**
- [ ] `debugBossNight` (บอสไม่ตาย → ฟื้น HP เต็ม) → **ยังติดล็อกอยู่**
- [ ] ฆ่าบอส (`debugBossDay` → `debugKillBoss`) → "กำจัดบอสแล้ว!" → หน้าต่างอัญเชิญ: ข้อความล็อกหาย · ปุ่มส่งกดได้อีก
- [ ] ปลดล็อกแล้ว**ทหารไม่เดินต่อเอง** — ต้องกด "ส่งไปรบ" ใหม่ (ผู้ใช้เลือก) → ตีด่าน 3 ต่อได้
- [ ] บอสตายแล้วพังกำแพงด่านถัดไประหว่างวันเดียวกัน → **ไม่ติดล็อก** (บอสไม่อยู่)
- [ ] คืนถัดไปบอสเกิดใหม่ → พังกำแพงด่านถัดไปอีกครั้ง → **ติดล็อกอีก**

local P1 = game.Players:GetPlayers()[1]

## 7. ผังใหม่ — พื้นปากเลน · กำแพงกั้น · หน้าป้อม

- [ ] **พื้นปากเลน**: พื้นสีน้ำตาลของเลน**เริ่มตรงแนวกำแพงหิน/ช่องประตูพอดี** — ไม่ยื่นออกมาบนหญ้าในลานแล้ว (เทียบภาพเดิมที่ส่งมา)
- [ ] ช่วงหน้าช่องประตู (ที่เคยเป็นแผ่นน้ำตาล) เป็น**หญ้าต่อเนื่อง** ไม่มีรอยต่อกระพริบ · แท่นอัญเชิญตั้งบนหญ้าตำแหน่งเดิม
- [ ] ทหาร (ภาพ) ยังโผล่ที่แท่นอัญเชิญแล้วเดินเข้าเลนเหมือนเดิม · ความเร็ว/ระยะการรบไม่เปลี่ยน
- [ ] กลางคืน: ดูกำแพงกั้นจาก**ในเลน** (ก่อนกลางคืนเดินเข้าไปรอ → ถูกวาปออกมา · ใช้กล้องมองข้าม) — ด้านหลังเรียบ ไม่มีช่องโหว่
- [ ] กลางคืน: ทหารที่กำลังเดินอยู่**ทะลุกำแพงกั้นขาว**ให้เห็น (ตั้งใจ — กำแพงกันเฉพาะผู้เล่น)

## 8. ไข่บอส — เกิด · ขนาด · ป้ายน้ำหนัก

- [ ] `debugBossNight` → **ไข่ 6 ฟองขึ้นมุมขวาของห้องบอสด่าน 1 หลังตัวบอส** (2 คอลัมน์ × 3 แถว) · ฝั่งซ้ายของห้องโล่งเป็นทางวิ่ง
- [ ] ไข่แต่ละฟอง**ขนาดตามน้ำหนัก** (ส่วนใหญ่ tier 1 ขนาดเท่ากัน) · มีป้ายน้ำหนักลอยเหนือไข่ `xxx กก.` ตรงกับ `debugBossEggs`
- [ ] 👥 สองเครื่องเห็นน้ำหนัก/ขนาดเดียวกัน
- [ ] กลางคืน/บอสยังอยู่ (`debugBossDay`) เดินไปชิดไข่ → **เห็นไข่แต่ไม่มีปุ่ม E**
- [ ] วิ่งผ่านห้องทาง**ฝั่งซ้าย** (−Z) ไปกำแพงด่าน 2 → ไม่เข้าใกล้บอส (เมื่อเปิดบอสตีกลับในอนาคตจะไม่โดน)

## 9. หยิบไข่ → วิ่งกลับเซฟโซน

- [ ] `debugKillBoss(P1)` → ไข่ทุกฟอง**มีปุ่ม E "หยิบไข่บอส"** (ขึ้นเฉพาะฟองที่ใกล้สุด) · ชื่อบนปุ่มบอกน้ำหนัก
- [ ] กด E **ค้าง 3 วิ** → หยิบได้ · toast "🥚 หยิบไข่บอสแล้ว (… กก.) — วิ่งกลับเซฟโซน…" · ไข่ฟองนั้นหายจากพื้น
- [ ] ไข่ลอย**เหนือหัว**ตัวเอง (ขนาดตามน้ำหนัก + ป้ายน้ำหนัก) · 👥 อีกเครื่องเห็นไข่บนหัวเราด้วย
- [ ] ถือไข่แล้ว**วิ่งเร็วเท่าเดิม** · กระโดดได้ปกติ · ไข่ไม่ชนอะไร
- [ ] ถืออยู่ → ปุ่ม E ของไข่ฟองอื่น**ไม่ขึ้น** (ถือทีละฟอง)
- [ ] วิ่งออกจากห้อง ผ่านปากเลน**เข้าลาน** → ทันทีที่พ้นแนวกำแพงหิน: toast **"เก็บไข่บอสแล้ว (… กก.)"** · ไข่บนหัวหาย
- [ ] เปิดกระเป๋า → แท็บไข่มี `ไข่ด่าน 1` **น้ำหนักตรงกับที่เห็นบนป้าย** (ไม่สุ่มใหม่) · เพิ่มแค่ **1 ฟอง** (ยืนในลานต่อก็ไม่ได้เพิ่ม)
- [ ] เดินกลับไปหยิบฟองถัดไปได้เรื่อย ๆ จนหมด 6 ฟอง · หมดแล้วไม่มีปุ่ม E อีก
- [ ] 👥 สองคนแย่งฟองเดียวกัน → คนที่กดครบก่อนได้ · อีกคน toast "ไข่ฟองนี้ไม่อยู่แล้ว"
- [ ] 👥 คนที่ไม่เคยตีบอสเลย (เข้ามาทีหลัง) ก็หยิบได้
- [ ] ยืนไกลแล้วพยายามหยิบ (ปุ่มไม่ขึ้นอยู่แล้ว) — ถ้ายิง remote ตรงจาก client ระยะไกล → toast "อยู่ไกลไข่เกินไป" ไม่ได้ไข่

## 10. เงินบอส

- [ ] 👥 A ตีบอส + ยืนในห้องจนบอสตาย · B ตีบอสแล้ว**ถอยออกไปลาน**ก่อนบอสตาย · C อยู่ในห้องแต่**ไม่ได้ตี**
- [ ] บอสตาย → **A ได้** toast "ได้ $10,000 จากบอส (แบ่ง 1 คน)" · **B และ C ไม่ได้** · เงินมุมขวาบนของ A เพิ่มตรงยอด
- [ ] ตีกันสองคนอยู่ในห้องทั้งคู่ → คนละ $5,000 "(แบ่ง 2 คน)" · สามคน → คนละ $3,333 (ปัดลง รวมไม่เกิน 10,000)
- [ ] ใช้ `debugKillBoss(P1)` ตอน P1 ยืนอยู่ในลาน (นอกห้อง) → **P1 ไม่ได้เงิน** (Output: "แบ่ง 0 คน")
- [ ] ออกเกมก่อนบอสตาย → ไม่ได้ (ไม่ error)

## 11. แจ้งเตือนไข่หนัก

- [ ] `debugBossNight` (สุ่มปกติ ส่วนใหญ่ไม่มีไข่หนัก) → **ไม่มีประกาศไข่หนัก**
- [ ] `debugBossNight` ใส่ `152300` → toast ทุกคน **"🥚 คืนนี้บอสเฝ้าไข่ 152,300 กก.!"** · ไข่ฟองที่ 1 ใหญ่กว่าฟองอื่นชัด
- [ ] `debugBossNight` ใส่ `100000` (เท่ากับเกณฑ์ ไม่เกิน) → **ไม่ประกาศ**

## 12. กรณีขอบ

- [ ] ถือไข่แล้ว**ออกเกม** (👥 ปิดหน้าต่างอีกเครื่อง) → ไข่**กลับจุดเดิม** มีปุ่ม E ให้คนอื่นหยิบ
- [ ] ถือไข่แล้ว **Reset ตัวละคร** → ไข่กลับจุดเดิม (ไม่ได้ไข่จากการเกิดใหม่ในคอก)
- [ ] ถือไข่ค้างไว้จนกลางคืน (`debugBossNight`) → ไข่บนหัว**หายก่อนวาป** · toast "…ไข่บอสที่ถืออยู่หายไป…" · วาปมาหน้าป้อมแล้ว**ไม่ได้ไข่**
- [ ] ไข่ที่ไม่มีใครหยิบ → คืนถัดไปหายหมด · **ไข่ชุดใหม่ 6 ฟอง**เกิดพร้อมบอสตัวใหม่ (น้ำหนักใหม่ ดูจาก `debugBossEggs`)
- [ ] บอสไม่ตายทั้งวัน → คืนถัดไปไข่ชุดเก่าหาย ชุดใหม่ขึ้นแทน · บอสฟื้น HP เต็ม
- [ ] (ถ้าทดสอบได้) กระเป๋าไข่เต็ม 10,000 → เข้าลานแล้ว toast "กระเป๋าไข่เต็ม — ถือไข่บอสไว้ก่อน…" **ไข่ยังอยู่บนหัว** · วางไข่ลงสวนฟัก (ที่ว่างเพิ่ม) → เข้ากระเป๋าเอง
