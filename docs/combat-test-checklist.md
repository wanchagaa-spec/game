# เช็คลิสต์ทดสอบ Studio — 5E-1 รบแบบชุด 6 ช่อง

> ⚠️ **ห้าม merge จนกว่าผู้ใช้สั่ง** · ดีไซน์เต็ม + ตารางต่อด่าน: `docs/data-schema.md` §7.13 · คำสั่ง debug: `docs/debug-commands.md`
> รอบนี้เป็น**ตรรกะฝั่ง server + ภาพชั่วคราว** (คนบล็อก ๆ + กล่อง) · โมเดลลูก/ภาพจริงทำ 5E-2
> คำสั่ง debug เรียกผ่านสะพานเสมอ: `game.ServerStorage.EggServiceDebug:Invoke("debugX", game.Players:GetPlayers()[1], ...)`

## 0. เตรียม

- [ ] เข้าเกมใน Studio (Play) · มีแม่ในคอก (ผลิตลูก) + แม่ในกระเป๋าอย่างน้อย 2 ตัว (`debugGrantMother` ได้)
- [ ] ผ่านด่าน 1 แล้ว (เปิดอัญเชิญครั้งแรก = ด่าน 1 พังทันที ไม่ต้องมีทหาร) · ด่านที่กำลังตี = ด่าน 2
- [ ] ถ้าอยากได้ลูกเร็ว: รอคลังสะสม หรือ `debugGrantMother` แม่หนักหลายตัวเข้าคอก

## 1. ชุดละ 6 ตัว — แม่ 1 (หลังสุด) + ลูก 5

- [ ] แท่นอัญเชิญ → แท็บลูกติ๊ก 1 กอง + แท็บแม่ติ๊ก 2 ตัว → ส่งไปรบ (ยืนยัน)
- [ ] กล่องยืนยันบอก **"แม่อาจตายถาวรระหว่างรบ (โดนศัตรู/ป้อมยิง) และแม่ที่เหลือทั้งหมดจะตายถาวรทันทีที่ด่านที่กำลังตีพัง"**
- [ ] ในเลนหน้ากำแพงด่าน 2: ฝั่งเรา 6 ตัว — ลูกเขียว 5 ตัวด้านหน้า · แม่ (เหลือง ใหญ่กว่าเล็กน้อย) ยืน**หลังสุด**
- [ ] ฝั่งศัตรู 6 ตัว (แดง) — **ตัวใหญ่ 1 ตัวใหญ่กว่าชัดเจน** + ตัวเล็ก 5
- [ ] ทุกตัวมีแถบเลือดเหนือหัว · เดินออกไกล ๆ แถบไม่ขยายตามจอ (ขนาดเป็น studs)
- [ ] `debugBattleStatus` → ช่อง 1–5 = ลูก · ช่อง 6 = แม่ตัวแรกที่ติ๊ก · ศัตรูช่อง 1 = ใหญ่

## 2. ตายแล้วตัวถัดไปแทนช่องเดิม · ลำดับตรงกับที่ติ๊ก

- [ ] ลูกหน้าสุดโดนรุม เลือดลดจนตาย → มีเอฟเฟกต์ตาย แล้วตัวใหม่เดินเข้าช่องเดิมทันที (ไม่รอ)
- [ ] ติ๊ก 2 กอง (A ก่อน B) → ลงสนามจากกอง A จนหมด แล้วค่อยมาจากกอง B (`debugBattleStatus` บรรทัด "คิวลูก")
- [ ] แม่ที่ช่อง 6 ตาย (ปล่อยให้ลูกหมดจนแม่ยืนหน้าสุด) → แม่ตัวถัดไปใน roster ลงช่อง 6 · toast **"แม่ตายในสนามรบ 1 ตัว (ตายถาวร)"**
- [ ] แม่ที่ตายกลางสนามหายจาก roster จริง (หน้าต่างอัญเชิญ "แม่ในสนามรบ X/10" ลดลง)

## 3. แม่หมด / ลูกหมด → เติมให้ครบ 6

- [ ] ไม่ส่งแม่เลย → ลูก 6 ตัว (ช่องแม่เป็นลูก)
- [ ] ไม่ติ๊กลูกเลย ส่งแม่ 8 ตัว → แม่ลง 6 ตัวพร้อมกัน อีก 2 ตัวรอคิว

## 4. รวมพล (ค3) — "กำลังรวมพล 7/12"

- [ ] คลังลูกที่ติ๊กเหลือน้อย (< 12) และแม่ในคอกยังผลิตกองนั้นอยู่ → สนามฝั่งเราว่างรอ
- [ ] HUD กลางบนขึ้น **"กำลังตีด่าน N · ⏳ กำลังรวมพล X/12"** · หน้าต่างอัญเชิญหัวบนขึ้น "⏳ กำลังรวมพล X/12"
- [ ] ครบ 12 → ลงสนาม 6 ตัวทันที (อีก 6 รอเติม) · ตัวเลขรวมพลหายไป
- [ ] ไม่มีแม่ในคอกผลิตกองที่ติ๊ก (ถอดแม่ออกจากคอก) + เหลือ 5 ตัว → ลงเท่าที่มี 5 ตัว ไม่รอ

## 5. ศัตรู · กำแพง · ป้อม

- [ ] หลอดกลางบน: **"ศัตรูเหลือ N ตัว · xx%"** ลดลงเรื่อย ๆ · **"กำแพง N HP · 100%"** ไม่ลดเลยตอนศัตรูยังเหลือ
- [ ] ศัตรูหมด → ศัตรูหายจากสนาม · ทหารเราเดินเข้าไปชิดกำแพง · หลอดกำแพงเริ่มลด
- [ ] **ป้อม** = กล่องเทาบนสันกำแพงด่านที่กำลังตี · มีเส้นยิงสีส้มสั้น ๆ ไปที่ตัวหน้าสุด ~ทุก 1 วิ
- [ ] ป้อมยิงทั้งตอนสู้ศัตรูและตอนตีกำแพง
- [ ] `debugTurret(false)` → ป้อม + เส้นยิงหาย · `debugBattleStatus` บอก "ป้อม ปิด (debug)" · `debugTurret(true)` → กลับมา
- [ ] เลขดาเมจลอยเหนือหน้ากำแพง (ของเดิม 3B-2) ยังขึ้นตอน HP ศัตรู/กำแพงลด

## 6. กำแพงพัง

- [ ] เหลือกำแพงน้อย ๆ (`debugSetStageProgress(player, 2, 0, 1)`) + มีทหาร → กำแพงพัง
- [ ] popup ผ่านด่านเหมือนเดิม (ไข่รางวัล + จำนวนแม่ที่ตายตอนด่านพัง)
- [ ] แม่ที่เหลือใน roster **ตายหมด** (กติกาเดิม) · ลูกที่รอดบนสนาม**กลับเข้ากอง** (จำนวนในกองไม่หาย)
- [ ] บอสห้องนั้นยังอยู่ → ติดล็อกอัญเชิญเหมือนเดิม · ทหารเราหายจากสนามทันที (กลับกอง)

## 7. ศัตรูบาดเจ็บคงสถานะ

- [ ] สู้จนศัตรูหลายตัวเลือดลด → กด "หยุดอัญเชิญ" → ทหารเราหาย (ไม่มีเอฟเฟกต์ตาย = กลับกอง) · **ศัตรูบาดเจ็บยังยืนอยู่ แถบเลือดเท่าเดิม**
- [ ] เปิดอัญเชิญอีกครั้ง → ตีต่อจากเลือดเดิม (ไม่เต็มใหม่)
- [ ] ออกเกมแล้วเข้าใหม่ → HP ทหารฝ่ายรับที่เหลือ (หลอด %) เท่าเดิม · แถวศัตรูสร้างใหม่ (แผลรวมอยู่ตัวแรก)

## 8. auto-pause

- [ ] ใช้งานปกติไม่ควรเกิดเลย (ทหารมีดาเมจเสมอ) — ถ้าเห็นคำเตือน "ตีไม่เข้า — หยุดปล่อยอัตโนมัติ" ระหว่างเล่นปกติ = บั๊ก แจ้งด้วย

## 9. ประสิทธิภาพ

- [ ] บนจอมีทหาร + ศัตรูไม่เกิน 12 ตัว + ป้อม 1 (Explorer: `Workspace.LocalTroops`)
- [ ] ผู้เล่น 2 คนตีคนละด่าน → แต่ละคนเห็นแค่สนามของตัวเอง
- [ ] ไม่มี warn "[CombatService] เหตุการณ์เกิน" / "[Main] TroopRenderer.updateFromPayload ล้มเหลว" ใน Output
