# แผนบอส + แย่งไข่ (แผนเต็มของผู้ใช้)

> บันทึกตามที่ผู้ใช้วางแผนไว้ตอนสั่ง Phase 5B · **ตอนนี้ทำจริงแค่บอสห้องด่าน 1 ห้องเดียว** (5A/5B)
> รอบ "บอสทุกห้อง" ทำหลังผู้ใช้ทดสอบ 5B ใน Studio แล้ว · ผังจริง/พิกัด: `docs/map-layout.md` §4.3–§4.4

## 1. แมพแบ่ง 2 โซน

| โซน | ครอบคลุม | กติกา |
|---|---|---|
| **เซฟโซน** | คอกทั้งหมด + ลานกลาง | ถือไข่บอสกลับมาถึง = ไข่เข้ากระเป๋า · กลางคืนทุกคนมารอที่นี่ (หน้าป้อม) |
| **สนามรบ** | ตั้งแต่ปากทางเข้าเลนเป็นต้นไป | กลางคืนปิดด้วยกำแพงกั้นที่ปากเลน · กลางวันเข้าไปสู้บอส/แย่งไข่ |

ห้องด่าน N = ช่วงเลนของด่าน N (ด่าน 1 = ปากเลน → กำแพงด่าน 2)

## 2. บอส 1 ตัวต่อห้องด่าน

- บอสอยู่**หลังกำแพงของด่านนั้น** · เข้าได้เฉพาะคนที่พังกำแพงด่านนั้นแล้ว
- **ไม่ต้องสู้พร้อมกัน** — ใครพังถึงห้องไหนก็ไปห้องนั้น · คนที่อยู่ด่านไกลกว่า**วิ่งผ่านห้องก่อนหน้าไปได้**
- **บอส + ไข่อยู่มุมซ้ายหรือขวา สลับฟันปลาต่อด่าน** (ด่าน 1 ขวา → ด่าน 2 ซ้าย → … หรือกลับกัน)
  เว้นอีกฝั่งเป็น**ทางวิ่งออกนอกระยะตีบอส** — คนวิ่งผ่านไม่โดนบอสตี
- รางวัลของห้อง (เงินบอส · ไข่) **เฉพาะคนที่อยู่ในห้องนั้น**

## 3. วงจร 10 นาที

| ช่วง | เวลา | เกิดอะไร |
|---|---|---|
| **กลางคืน** | 1 นาที | บอสเกิด + ไข่ 6 ฟอง · กำแพงกั้นปิดทางเข้า · ตัวเลขนับถอยหลัง 59 → 0 |
| **กลางวัน** | 9 นาที | เช้า กำแพงกั้นเปิด · สู้บอสได้ทั้งวัน |

- บอสอยู่จนกว่าจะโดนฆ่า หรือเกิดใหม่ตอนคืนถัดไป (ยังไม่ตาย = ฟื้น HP เต็ม)
- ไข่หยิบได้หลังบอสตาย · ถือกลับเซฟโซน = ได้ · ไข่ที่ไม่มีใครหยิบหายตอนคืนถัดไป

## 4. ยังไม่ตัดสิน (รอรอบ "บอสทุกห้อง")

- **กลางคืนวาปไปที่ไหน** — ไปห้องด่านของแต่ละคนเอง หรือที่เดียว (หน้าป้อมกลาง)
  ตอนนี้ (บอสห้องเดียว) = ทุกคนวาปมาหน้าป้อมฝั่งลาน
- **ล็อกอัญเชิญผูกกับบอสห้องที่เพิ่งพังเข้าไปหรือไม่** — ตอนนี้ (5A) = ผูกกับบอสกลางตัวเดียว
  (พังกำแพงด่านไหนก็ตามขณะบอสกลางยังอยู่ → ติดล็อกจนบอสกลางตาย)
