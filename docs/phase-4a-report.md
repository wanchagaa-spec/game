## 2. Phase 4A — ดีไซน์ที่ตกลง

โจทย์: กำแพงด่านไหนพังเป็น**ครั้งแรก** → ได้ **ไข่ฟรี** (ไม่ใช่เงิน) เข้ากระเป๋าไข่ ยังไม่ฟัก

| เรื่อง | ตัดสิน |
|---|---|
| รางวัลเป็นอะไร | **ไข่** ไม่ใช่เงิน — เงินเพิ่งถูกดูดส่วนเกินด้วย `DamageUpgrade` ใส่เงินก้อนเพิ่ม = ย้อนปัญหาเดิม |
| ไข่ชนิดไหน | `egg_stageN` = ไข่ของรังบอสด่านที่เพิ่งปลดล็อก (กำแพงด่าน N อยู่หน้ารังบอสด่าน N) |
| สุ่มยังไง | ผ่าน `EggService.grantEgg` ตัวเดียวกับไข่ทุกแหล่ง — น้ำหนักสุ่มตอนสร้าง · คลาสสุ่มตอนวางลงสวนฟัก · ไม่มี logic สุ่มใหม่ |
| จำนวนต่อด่าน | ด่าน 1 = **0** · 2–3 = 1 · 4–6 = 2 · 7–9 = 3 → รวม 17 ฟองทั้งเกม |
| ให้ซ้ำได้ไหม | **ไม่ได้** — ธงต่อด่าน `stageClearBonusGranted` (9 ช่อง) |
| ผู้เล่นเก่า | **ไม่ได้ไข่ย้อนหลัง** สำหรับด่านที่พังไปก่อนอัปเดต |
| แจ้งผู้เล่น | remote ใหม่ `StageClearedNotify(stage, eggCount)` server → client · popup แยกจาก ActionResult |

### 2.1 จุดที่ต่างจากโจทย์เดิม (ทักท้วงแล้ว ผู้ใช้เลือกข้อ 1)

| โจทย์เดิม | ปัญหาที่เจอในโค้ดจริง | ที่ทำจริง |
|---|---|---|
| ให้รางวัลใน `recomputeWallProgress` | ฟังก์ชันนี้ไล่นับด่านที่ "พังอยู่" ทั้งหมดใหม่ทุกครั้ง → ผู้เล่นเก่าที่ธงเป็น false ได้ไข่ย้อนหลังทุกด่าน · `debugSetStageProgress` ก็เรียกมันด้วย | ให้ใน `CombatService.tick` ตรงจังหวะ `stageCleared` (ด่าน**เพิ่ง**พังในตานี้) |
| ตารางให้ด่าน 1 = 1 ฟอง | ด่าน 1 ไม่มีกำแพง/ทหาร "พัง" ฟรีตั้งแต่ตาแรกที่ปล่อยทหาร — ผู้เล่นใหม่จะได้ไข่ + popup ทั้งที่ไม่ได้สู้ | ด่าน 1 = 0 · `validate()` บังคับว่าด่าน HP รวม 0 ต้องเป็น 0 |
| ไม่ได้ระบุชนิดไข่ | — | `egg_stageN` |

**เรื่องสมดุล (ไม่คัดค้าน):** 17 ฟองทั้งเกม เทียบไข่จากบอส ~10 ฟอง/ชม. ตลอด ~54 ชม. ถึงด่าน 9 ≈ **3%**
ไม่กระทบเงินหรือเวลาฟัก — เป็นรางวัลฉลอง ไม่ใช่ตัวปรับเศรษฐกิจ

### 3.1 เส้นทางการให้รางวัล

```
CombatService.tick → applyDamageToStage คืน stageCleared = true   ← ด่านนี้เพิ่งพังในตานี้
  → recomputeWallProgress → killRoster
  → claimStageClearBonus(data, stage)
       ด่าน HP รวม 0 → 0 · ธง true อยู่แล้ว → 0 · ไม่งั้นติดธง true แล้วคืนจำนวนไข่
  → (ลูปใน CombatService.start) EggService.grantStageClearBonus(player, stage, จำนวน)
       → grantEgg × จำนวน → FireClient StageClearedNotify(stage, จำนวนที่แจกได้จริง)
```

- ด่านที่พังแล้วไม่มีวันพังซ้ำ (ตีเรียงลำดับ ไม่ย้อนด่าน) → ผู้เล่นเก่าไม่เกิดจังหวะ "เพิ่งพัง" กับด่านเก่า → ไม่ได้ไข่ย้อนหลัง
- แจ้งครั้งเดียวทาง remote **ไม่อยู่ใน sync** → resync กี่รอบ popup ก็ไม่โผล่ซ้ำ
