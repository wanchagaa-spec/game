# เช็คลิสต์ทดสอบ Studio — โมเดลตัวละคร (ประกอบจาก Part 12 ตัว · ลิง rig R6) + เปลี่ยนชื่อ 2 ตัวละคร

> **รอบนี้ทำอะไร**
> - โมเดลแม่ **ครบ 12 ตัวประกอบจาก Part ในโค้ด** (`src/shared/MotherModels.lua`)
> - **ลิงทำใหม่ (ผู้ใช้สั่ง)**: เลิกใช้ mesh เดิม → บล็อก + **rig R6** (Motor6D 6 ตัวตาม rig R6 ของ Roblox) + **อนิเมชันตั้งต้นของ Roblox**
>   เดิน `180426354` · ยืน `180435571` · เหวี่ยงแขน `129967390` (ท่าพัก "ต่อย") — เล่นผ่าน AnimationController ไม่ใช่ Humanoid
> - เปลี่ยนชื่อ 2 ตัว **คง charId เดิม**: `yulai` องค์ยูไล → **ราชาปีศาจวัว** (SS) · `guanyin` พระแม่กวนอิม → **องค์หญิงพัดเหล็ก** (S) — ไม่มี migration
> - ขนาดตามคลาส `VisualScale.CLASS_MULTIPLIER` C 1.0 · B 1.1 · A 1.2 · S 1.35 · SS 1.5 (คูณเพิ่มจากตัวคูณน้ำหนัก · เฉพาะโมเดล กล่องสีสำรองคงเดิม)
> - ท่าขยับในคอก (โมเดล Part ไม่มีอนิเมชัน): **กระเด้งเบา ๆ ตอนเดิน** · **ปลาลอยเหนือพื้นขยับขึ้นลงตลอด**
> - รูปการ์ด (กระเป๋า · ดัชนี · หน้าต่างอัญเชิญ · ร้านขาย · แผงเท้า) เปลี่ยนเป็น**มุมเฉียง 3/4** + ถอยกล้องให้ไม่ล้นกรอบ (ลิงก็เปลี่ยนมุมด้วย)
> - คำสั่ง debug ใหม่: `debugShowcaseModels` · `debugClearShowcase` · `debugGrantAllCharacters` (`docs/debug-commands.md`)
>
> เทสต์อัตโนมัติ (`python3 tools/check-all.py`) ตรวจแล้ว: ทุกตัวละครมีโมเดล · ≤ 40 ชิ้น · PrimaryPart · ทุกชิ้นไม่ชน · ตัวใหญ่สุด tier 7 อยู่ในคอก ·
> การ์ดจัดกรอบไม่ล้น (ใช้กรอบ 82–92%) · ข้อต่อ rig ลิงตรง R6 ของ Roblox (เทียบค่า C0/C1 ทุกข้อ) · เงาดำทำงาน · ชื่อเดิมไม่เหลือในโค้ด — **หน้าตา ความน่ารัก การเดิน และความลื่น ต้องดูใน Studio**
> ⚠️ **ห้าม merge จนกว่าผู้ใช้สั่ง**

## 0. เตรียม

1. `rojo serve` → Studio เชื่อม Rojo → กด **Play**
2. Output ต้อง**ไม่มี** `[PenService] แบบโมเดลผิดกติกา` · `ประกอบโมเดล "…" จาก Part ไม่สำเร็จ`
3. คำสั่งทั้งหมดเรียกจาก Command Bar ฝั่ง **Server** ผ่าน `game.ServerStorage.EggServiceDebug:Invoke(...)`

## 2. การ์ด · ดัชนี · หน้าต่างต่าง ๆ

```lua
local P1 = game.Players:GetPlayers()[1]
game.ServerStorage.EggServiceDebug:Invoke("debugGrantAllCharacters", P1)
```

- [ ] กระเป๋า: ได้แม่ใหม่ 12 ตัว (100 kg) · **ทุกการ์ดเป็นรูปโมเดล** มุมเฉียง 3/4 (เห็นหน้า + ด้านข้าง) · ไม่มีตัวไหน**ล้นขอบการ์ด**/ถูกตัดหัว/ถูกตัดของที่ถือ
- [ ] ตัวเล็ก (ปลา · หมู) ไม่เล็กจิ๋วในการ์ด · ตัวยาว (ม้า · ม้าขาวมังกร) เห็นทั้งตัว
- [ ] กดการ์ด → หน้ารายละเอียด: รูปใหญ่ถูกตัว · ชื่อใหม่ **ราชาปีศาจวัว / องค์หญิงพัดเหล็ก**
- [ ] ดัชนี 📖: "เก็บแล้ว 12/12" · แท็บ S = องค์หญิงพัดเหล็ก · เง็กเซียน · แท็บ SS = ราชาปีศาจวัว · รูปทุกตัวเป็นโมเดล
- [ ] **เงาดำ**: ใช้ผู้เล่นใหม่ (หรือ `debugWipeSavedData` แล้วเข้าใหม่) → ตัวที่ยังไม่เคยได้เป็น**เงาโมเดลสีดำทั้งตัว** + "???" (ไม่ใช่กล่องดำ)
- [ ] หน้าต่างอัญเชิญ (แท่นในเลน · แท็บแม่) · ร้านขายแม่ (แผง 1) · แผงเท้า (แม่ในคอก) → รูปโมเดลทุกตัว ไม่ล้นกรอบ
- [ ] ลิง: รูปการ์ดเป็น**ลิงบล็อกตัวใหม่** (ไม่ใช่ mesh เดิม) ท่ายืนตรง · ไม่มีกล่องใส (HumanoidRootPart) โผล่ในรูป
- [ ] ข้อความทุกที่ (toast ฟักไข่ · หน้ารายละเอียด · ป้ายชื่อเหนือแม่ในคอก) ไม่มีคำว่า "ยูไล" / "กวนอิม" เหลือ

## 3. ในคอก (เดิน · ขนาด · ประสิทธิภาพ)

- [ ] กด **"สวมใส่ที่ดีที่สุด"** (แผงเท้า) ให้แม่หลายแบบเข้าคอก · หรือย้ายเข้าคอกเองทีละตัว
- [ ] ทุกตัวยืนบนพื้นพอดี · **เดินไปมา + กระเด้งเบา ๆ ตอนเดิน** แล้วหยุดพักนิ่ง (ไม่ลอยขึ้นเรื่อย ๆ หลังเดินหลายรอบ)
- [ ] เดินหันหน้าไปทางที่เดิน (หน้า ไม่ใช่หลัง/ข้าง)
- [ ] **ปลาลอย**ขึ้นลงช้า ๆ ตลอด (ทั้งตอนว่ายและตอนหยุด) ไม่จมพื้น
- [ ] ป้ายชื่อ+น้ำหนักเหนือหัวอยู่เหนือตัวพอดี (ชื่อใหม่)
- [ ] ตัวใหญ่สุด: `debugGrantAllCharacters(P1, 100000000)` → ย้ายราชาปีศาจวัว / องค์หญิงพัดเหล็ก / เง็กเซียน tier 7 เข้าคอก →
  **ไม่ยื่นทะลุรั้ว** ตอนเดินชิดขอบ (เทสต์คำนวณไว้: ราชาปีศาจวัว tier 7 สูง ~49 · ครึ่งเส้นทแยงพื้น 23.7 จาก 36 ที่ว่างในรั้ว)
- [ ] 👥 (ถ้าทำได้) หลายคนคอกเต็มพร้อมกัน → เฟรมเรตไม่ตก / เดินไม่กระตุกกว่ากล่องสีเดิมอย่างเห็นได้ชัด
- [ ] **ลิง (rig R6)** ในคอก: เดิน = **แกว่งแขนขาแบบตัวละคร Roblox** (ไม่กระเด้ง) · หยุด = ท่ายืน → ท่าเหวี่ยงแขน สลับกันทุกครั้งที่หยุด
- [ ] ท่าเล่น**ต่อเนื่องบนจอผู้เล่น** (ไม่เล่นรอบเดียวแล้วค้าง) · 👥 อีกเครื่องเห็นท่าเดียวกัน
- [ ] เท้าไม่ไถล/ไม่ย่ำอยู่กับที่เกินไป (ถ้าไม่พอดี แจ้งได้ — ปรับ `walkAnimSpeed` ของลิงใน MotherModels ได้ ตอนนี้ 0.55)
- [ ] ลิง tier 7 (ตัวใหญ่) ข้อต่อไม่หลุด แขนขาอยู่ที่เดิม · Output ไม่มี warn `โหลดอนิเมชันท่า …ไม่สำเร็จ`
