# tools — สร้างตารางสมดุลจาก Config

## รันยังไง

```bash
python3 tools/gen-balance-tables.py
```

เขียนทับ `docs/balance-tables.html` เปิดด้วยเบราว์เซอร์ได้เลย
ต้องมี **luau CLI** อยู่ใน PATH (หรือสั่ง `LUAU=/path/to/luau python3 tools/gen-balance-tables.py`)

---

## ทำงานยังไง

```
src/shared/Config.lua
        │  luau tools/dump-balance.luau
        ▼
   TSV ทาง stdout          ← ตัวเลขดิบทุกตัว คำนวณด้วยฟังก์ชันจริงใน Config
        │  tools/gen-balance-tables.py
        ▼
docs/balance-tables.html
```

แยกสองขั้นเพราะ **ตัวเลขต้องมาจาก Config จริง** ฝั่ง Python ห้ามรู้สูตรอะไรเองเลย
ถ้าต้องการค่าใหม่ในหน้า ให้เพิ่ม `row(...)` ใน `dump-balance.luau` ก่อน แล้วค่อยไปอ่านฝั่ง Python

## ⚠️ กฎข้อเดียวของไฟล์นี้: ห้ามพิมพ์ตัวเลขลงในข้อความบรรยาย

หัวไฟล์ HTML เขียนว่า "ตัวเลขทุกตัวดึงจาก Config โดยตรง ไม่ได้พิมพ์มือ"
**ตารางทำตามนั้นมาตลอด แต่ย่อหน้าคำอธิบายไม่ได้ทำ** — เคยพิมพ์ตัวเลขลงประโยคตรง ๆ
พอปรับสมดุลรอบถัดไป ตารางขยับแต่ข้อความค้างอยู่ที่ค่ารอบเก่า กลายเป็นขัดกันเองในหน้าเดียว
(เช่น ข้อความเขียน `2.35×` ขณะที่ตารางข้าง ๆ เป็น `3.17×`)

ตอนนี้แก้แล้ว — ทุกตัวเลขในย่อหน้ามาจาก f-string ที่คำนวณจากข้อมูลจริง

**เวลาแก้ไฟล์นี้:**

```python
# ❌ ห้าม
W('''<div class="key">ตอนนี้อัตราส่วนสูงสุดคือ <b>2.35×</b> ที่ด่าน 4</div>''')

# ✅ เอาแบบนี้
_nr = max(PATH, key=lambda r: float(r[6]) / float(r[5]))
W(f'''<div class="key">ตอนนี้อัตราส่วนสูงสุดคือ
<b>{float(_nr[6])/float(_nr[5]):.2f}×</b> ที่ด่าน {_nr[0]}</div>''')
```

ตัวเลขที่ยังพิมพ์ตรง ๆ ได้มีแค่ **ค่าคงที่เชิงดีไซน์ที่ `validate()` ตรึงไว้อยู่แล้ว**
เช่น "ลูกแรง 10% ของแม่เสมอ เพราะ √0.01 = 0.1" — ถ้าค่านั้นเปลี่ยน เซิร์ฟจะไม่บูตก่อน

### ตรวจว่ายังไม่มีใครเผลอพิมพ์มือ

```bash
python3 tools/check-hardcoded-numbers.py
```

สแกนบล็อกข้อความทั้งหมดแล้วรายงานตัวเลขที่ไม่ได้อยู่ใน `{...}` — ใช้ดูว่ามีอะไรหลุดไหม
(ไม่ได้ fail อัตโนมัติ เพราะค่าคงที่เชิงดีไซน์ก็ติดมาด้วย ต้องใช้ตาคนอ่าน)

## กันพลาดที่ฝั่ง dump

`row()` **assert ว่าไม่มีค่าไหนเป็น `nil`** ก่อนพ่นออกมา

จำเป็นเพราะ `{...}` ใน Luau ที่มีค่า `nil` จะกลายเป็นอาเรย์มีรู แล้ววนหยุดกลางทาง →
คอลัมน์หายเงียบ ๆ โดยไม่มี error เกิดขึ้นจริงมาแล้วตอนเปลี่ยนชื่อค่าใน Config
(`Config.Hatchery.MAX_EGGS` → `MAX_SLOTS`) ตอนนี้เจอแบบนั้นจะดังทันทีพร้อมบอกว่าแถวไหน
