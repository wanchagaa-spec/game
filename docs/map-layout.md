## 1. ผังรวม

**แมพเป็นลานหญ้าเปิดโล่งบนแท่นลอย ไม่มีกำแพงล้อมรอบแมพ**
ที่เดียวที่มีกำแพงข้างคือ **เลนรบ** · ขอบแมพกันด้วย**กำแพงใส** (ดู §5)

มองจากด้านบน · X เดินซ้าย→ขวา · Z เป็นแกนขวาง · พื้นทุกอย่างอยู่ที่ Y = 0

```
             ลานคอก 6 แปลง (2 แถว หันหน้าเข้าหากัน · รั้วไม้เตี้ยล้อม)
   +Z   ┌──────────┐ ┌──────────┐ ┌──────────┐
 ┌───┐  │  คอก 1   │ │  คอก 2   │ │  คอก 3   │      ▓ แท่นปล่อยทหาร
 │แผง│  └──────────┘ └──────────┘ └──────────┘      ║
 └───┘ ═══════════ ทางเดินกลาง ═══════════════════╗ ║  ┃━━━━━━━━━━━ กำแพงข้างเลน
 ┌───┐  ┌──────────┐ ┌──────────┐ ┌──────────┐    ╚═╩══  เลนรบ →→→→→→→→→→
 │แผง│  │  คอก 4   │ │  คอก 5   │ │  คอก 6   │       ┃━━━━━━━━━━━ กำแพงข้างเลน
 └───┘  └──────────┘ └──────────┘ └──────────┘       ด่าน 1 ─ 2 ─ … ─ 9
   −Z
  X=−154   X=−88     X=0      X=+88          X=+128 ──────────────► X=+1748
        └──────────── ลานหญ้าเปิดโล่ง ──────────────┘
```

### พิกัดจริงที่ค่าปัจจุบันให้

| ของ | พิกัด |
|---|---|
| แผงร้านค้า | 2 แผงที่ `X = −166` · `Z = −51` และ `Z = +51` (ขนาบทางเดินกลาง) |
| ลานคอก | `X = −140 … +140` (กว้าง 280) · แถวบน `Z = +85` · แถวล่าง `Z = −85` (ลึกรวม 250) |
| พื้นหญ้าทั้งผืน | `X = −242 … +140` · `Z = −195 … +195` = **382 × 390 studs** (รวมแถบหญ้านอกกำแพงใส) |
| จุดเกิดผู้เล่น | ทางเดินกลางหน้าคอกของตัวเอง (ดู §3) · จุดเกิดกลางที่ `(0, 0, 0)` |
| ต้นเลนรบ (จุดปล่อยทหาร) | `X = +140` ต่อจากลานคอกทันที |
| เลนรบ | `X = +140 … +1760` ยาว **1,620** (180 × 9) กว้าง 60 กึ่งกลาง `Z = 0` |
| ขอบพื้นทั้งแมพ | `X = −242 … +1760` · `Z = −195 … +195` = **2,002 × 390 studs** |
| กรอบกำแพงใส | `X = −192` · `Z = ±145` (ถอยเข้ามาจากขอบพื้น 50) |

### ช่วงของแต่ละด่าน

ด่าน N กินช่วง X ยาว `LANE_LENGTH_PER_STAGE` · **กำแพงอยู่ต้นช่วง · รังบอสอยู่ท้ายช่วง**

| ด่าน | ช่วง X | กำแพงที่ X | รังบอสที่ X | วิ่งจากต้นเลนถึงรัง |
|---:|---|---:|---:|---:|
| 1 | 140 – 320 | **ไม่มี** | 270 | 4.1 วิ |
| 2 | 320 – 500 | 320 | 450 | 9.7 วิ |
| 3 | 500 – 680 | 500 | 630 | 15.3 วิ |
| 4 | 680 – 860 | 680 | 810 | 20.9 วิ |
| 5 | 860 – 1040 | 860 | 990 | 26.6 วิ |
| 6 | 1040 – 1220 | 1040 | 1170 | 32.2 วิ |
| 7 | 1220 – 1400 | 1220 | 1350 | 37.8 วิ |
| 8 | 1400 – 1580 | 1400 | 1530 | 43.4 วิ |
| 9 | 1580 – 1760 | 1580 | 1710 | 49.1 วิ |

⚠️ **ด่าน 1 ไม่มีกำแพง** ผู้เล่นใหม่เดินเข้ารังบอสด่าน 1 ได้ทันทีที่เข้าเกม
(แก้ปัญหาไก่กับไข่: ต้องมีแม่ถึงจะมีกองทัพ ต้องมีไข่ถึงจะมีแม่)
`validate()` บังคับข้อนี้ด้วย `Config.getWallX(1) == nil`

> ⚠️ ตัวเลขในตารางนี้พิมพ์ไว้เพื่ออ่านง่าย **ของจริงคำนวณจาก Config เสมอ**
> ปรับ `MapDimensions` แล้วรัน `luau tools/dump-map.luau` เพื่อดูชุดใหม่ (§8)

## 2. กฎที่สำคัญที่สุด: อะไรวาด client อะไรอยู่ server

| ของ | อยู่ฝั่งไหน | ทำไม |
|---|---|---|
| ลานหญ้า · คอก · เลนรบ · ห้องบอส · แผงร้าน · **กำแพงใสขอบแมพ** | **server** | เป็นพื้นที่ร่วม ทุกคนต้องเห็นเหมือนกัน |
| ตัวแม่ในคอก · ไข่ที่กำลังฟัก | **server** | เห็นฟาร์มของคนอื่นได้ เป็นของจริงไม่ใช่ภาพลวง |
| บอส · ไข่ในรัง | **server** | ของกลางที่ทุกคนแย่งกัน (Phase 5) |
| **กำแพงกั้นด่าน 9 ด่าน** | **client** | ดูข้างล่าง |
| **ทหารฝ่ายรับ** | **client** | เห็นเฉพาะของตัวเอง |
| **กองทัพของผู้เล่นเอง** | **client** | เห็นเฉพาะของตัวเอง |

⚠️ **กำแพงสองข้างเลน ≠ กำแพงกั้นด่าน** — คนละอย่างกันคนละฝั่งกัน:

| | กำแพงข้างเลน | กำแพงกั้นด่าน |
|---|---|---|
| ทำหน้าที่ | กันตกออกข้างเลน | กันเข้าด่านที่ยังตีไม่ผ่าน |
| วาดฝั่ง | **server** | **client** |
| วางแนว | ขนานเลน ตลอดเส้น | ขวางเลน ที่ต้นช่วงแต่ละด่าน |

### ทำไมกำแพงกั้นด่านต้องวาดฝั่ง client

ผู้เล่นทุกคนใช้ **เลนเส้นเดียวกัน** แต่แต่ละคนพังกำแพงมาถึงคนละด่าน
ถ้าสร้างกำแพงบน server จะมีกำแพงชุดเดียวให้ทุกคน ซึ่งแยกไม่ได้ว่าใครผ่านแล้วบ้าง

**ผลพลอยได้ที่ตั้งใจ — การชนแยกกันเองฟรี ๆ**

Part ที่สร้างจาก LocalScript ชนเฉพาะเครื่องของเจ้าของ ดังนั้น:

```
คนที่พังด่าน 3 แล้ว  →  ไม่มีกำแพงด่าน 3 บนเครื่องเขา  →  เดินผ่านได้
คนที่ยังไม่พัง        →  มีกำแพงด่าน 3 บนเครื่องเขา     →  เดินชน
```

ทั้งสองคนยืนที่พิกัดเดียวกันในโลก แต่ได้ผลต่างกัน **โดยไม่ต้องเขียนโค้ดเช็คสิทธิ์เพิ่มเลย**

### ⚠️ ผลข้างเคียงที่ยอมรับแล้ว — ไม่ต้องแก้

**จะเห็นคนอื่นเดินทะลุกำแพงที่ตัวเองยังพังไม่ได้**

เป็นราคาที่จ่ายเพื่อให้ได้การชนแบบแยกคน บันทึกไว้ตรงนี้เพื่อไม่ให้มีใครเจอแล้วคิดว่าเป็นบั๊ก
ถ้าวันหนึ่งรับไม่ได้จริง ๆ ทางแก้คือซ่อนตัวละครคนอื่นตอนอยู่คนละด่าน ซึ่งแพงกว่ามาก

### ความปลอดภัย

`wallProgress` ฝั่ง client เปลี่ยนแค่ **สิ่งที่เห็นและชนบนเครื่องนั้น**
ไม่ได้ให้สิทธิ์อะไรเพิ่มจริง เพราะการตีกำแพง การให้รางวัล และการอัป `wallProgress`
คำนวณฝั่ง server ทั้งหมด (Phase 3) — คนที่แก้ค่าฝั่งตัวเองจะเดินไปยืนเฉย ๆ ในด่านที่ยังตีไม่ได้

## 3. ลานคอก

- **6 แปลง** วาง 2 แถว แถวละ 3 หันหน้าเข้าหากัน · แปลงละ **80 × 80 studs**
- ระหว่างสองแถวเป็นทางเดินกลางกว้าง **90** เชื่อมแผงร้าน (ซ้าย) กับต้นเลนรบ (ขวา)
  ⚠️ **ต้องกว้างไม่น้อยกว่าเลนรบ (60)** ไม่งั้นปากทางเข้าเลนเป็นคอขวด · `validate()` บังคับ
  (เดิม 30 = ครึ่งเดียวของเลน · คอกแถวบนกินถึง `Z = 15` ซึ่งล้ำเข้ามาในแนวเลน)
- แต่ละแปลงเป็นของผู้เล่นคนหนึ่ง จองตอนเข้าเกม คืนตอนออก (`PenService`)
- **เห็นฟาร์มของคนอื่นได้** คอกและแม่ในคอกเป็นของจริงบน server

⚠️ **จำนวนแปลงต้องเท่ากับ `PLAYERS_PER_SERVER` เป๊ะ** `validate()` บังคับสองชั้น:
`PEN_ROWS × PEN_PER_ROW == MAX_PENS` และ `MAX_PENS == PLAYERS_PER_SERVER`
เกิน = มีคอกร้างที่ไม่มีวันมีเจ้าของ · ขาด = ผู้เล่นเข้ามาแล้วไม่มีที่ยืน

### ⚠️ `MaxPlayers` ต้องตรงด้วย — และเป็นชั้นที่ repo คุมไม่ได้ทั้งหมด

`default.project.json` ตั้ง `Players.MaxPlayers = 6` ไว้แล้ว
**แต่ค่านี้แก้ได้จากหน้า Game Settings บนเว็บ Roblox ด้วย ซึ่งทับค่าในไฟล์ได้และ repo มองไม่เห็น**

`Main.server.lua` จึงเช็คซ้ำตอนบูตแล้ว `warn()` ถ้าไม่ตรง —
เป็นชั้นเดียวที่จับได้เมื่อมีคนไปแก้บนเว็บ

ถ้าปล่อยให้ไม่ตรง: คนที่เกินมาจะเข้าเกมได้แต่ `PenService.assign()` คืน `nil`
→ เดินได้ แต่ไม่มีคอก วางไข่ไม่ได้ (`placeEgg` ปฏิเสธด้วย "ยังไม่ได้รับคอก")

### ภายในคอก

- **พื้นในคอกเป็นหญ้าทั้งผืน ไม่มีแปลงหรือช่องตาราง**
- **ทางเดินกลางก็เป็นหญ้า** กลืนกับพื้นรอบข้าง ไม่มีเส้นแบ่งให้เห็น
  (เดิมเป็นแถบพื้นเทาซึ่งอ่านเป็น "ถนน" ทั้งที่มันคือลานหญ้าผืนเดียวกัน)
- **ตัวแม่เดินไปมาได้อิสระ** ทั่วทั้งคอก
- **ไข่วางตรงไหนก็ได้** ในคอก ไม่มีแท่นฟักเป็นช่อง
- `PEN_EDGE_MARGIN` (4) กันไม่ให้แม่กับไข่ไปยืนซ้อนกับรั้ว

### รั้ว ประตู และป้ายชื่อ

**รั้วไม้เตี้ย** สูง 3 หนา 1 — เสาเล็ก ๆ ทุก 8 studs + คานแนวนอน 2 ชั้น (แบบรั้วฟาร์มปกติ)

⚠️ **`CanCollide = false` ทุกชิ้น ผู้เล่นและแม่เดินทะลุได้**
รั้วไม่ได้ทำหน้าที่กันอะไรเลย เป็นแค่เครื่องหมายบอกว่าคอกใครถึงไหน

> **ทำไมรั้วถูกยกเว้นจากกฎความหนา-ความเร็ว** (§7)
> กฎนั้นมีไว้กับกำแพงที่ต้อง **หยุด** ผู้เล่น · รั้วไม่ได้หยุดอะไร ทะลุอยู่แล้วโดยตั้งใจ
> เคยเอารั้วเข้ากฎนี้แล้วต้องดันให้หนา 5 จนกลายเป็น "กำแพงเตี้ย" ไม่ใช่รั้ว
> `validate()` จึงตัดรั้วออกจากรายการนั้นโดยเฉพาะ พร้อมคอมเมนต์กำกับว่าทำไม

**ประตู** — ทำโดย **เว้นช่องกลางรั้วกว้าง 8 studs** ด้านที่หันเข้าทางเดินกลาง
ไม่มีบานประตูเปิด/ปิด แค่เว้นช่อง · ทั้ง 6 คอกหันประตูเข้าทางเดินกลาง
(คอก 1–3 แถวบนหันลง · คอก 4–6 แถวล่างหันขึ้น)

**ป้ายชื่อ** — เสาไม้ + ป้าย ปักบนหญ้าด้านนอกคอก **ข้างประตู ไม่ใช่กลางประตู** (กันเดินชน)
ยกสูง 5 studs ให้อ่านได้จากมุมกล้องปกติ · ข้อความตั้งโดย `PenService` เหมือนเดิม

⚠️ **แม่ยังเดินอยู่แค่ในคอก** แม้รั้วจะทะลุได้ — ขอบเขตสุ่มเดินอ่านจาก **พิกัดคอก**
(`getPenPlotCenter` + `PEN_EDGE_MARGIN`) ไม่ได้อ่านจากรั้ว
รั้วหายไปทั้งเส้นแม่ก็ยังเดินเท่าเดิม

### จุดเกิดผู้เล่น — เกิดใกล้คอกตัวเอง

ลานกว้างขึ้นมาก เกิดกลางลานแล้วต้องวิ่งข้ามไปหาคอกทุกครั้งที่ตายจะน่ารำคาญ
`MapBuilder.buildSpawns()` จึงสร้าง **`SpawnLocation` หนึ่งจุดต่อคอก**
วางที่ทางเดินกลางตรงหน้าคอกแปลงนั้นพอดี (`Config.getSpawnPointForPen(index)`)
แล้ว `Main.server.lua` ตั้ง `player.RespawnLocation` ให้หลังจองคอกเสร็จ

**ทำไมใช้ `SpawnLocation` ไม่ใช่ย้ายตัวละครเองตอน `CharacterAdded`:**

| | `SpawnLocation` + `RespawnLocation` (ที่ใช้) | ย้ายเองตอน `CharacterAdded` |
|---|---|---|
| เฟรมแรก | อยู่ถูกที่ตั้งแต่ต้น | โผล่กลางลานแล้ววาร์ป |
| ตอนเกิดใหม่หลังตาย | ได้ฟรี | ต้องต่อ event เองทุกครั้ง |
| โค้ดที่ต้องดูแล | ตั้งค่าครั้งเดียวตอนจองคอก | ต้องจำว่าต้องตั้งซ้ำ |

`validate()` assert ว่าจุดเกิดทุกจุด **อยู่บนพื้นลาน** และ **อยู่ในทางเดินกลาง**
(ไม่ไปโผล่ในคอกคนอื่น) — แมพเป็นแท่นลอย หลุดขอบเมื่อไหร่ = ตกตั้งแต่วินาทีแรก

### ✅ ลานคอกติดเลนรบได้ ไม่ต้องมีสิ่งกั้น

ลานคอกอยู่ติดเลนรบ แต่ **ไม่ต้องสร้างกำแพงหรือประตูกั้นระหว่างสองโซน**
เพราะกติกา "ห้ามส่งแม่ในคอกไปรบ" ถูกกันด้วย **โครงข้อมูล** ไม่ใช่ด้วยกำแพง:

```
mothersInPen  ──┐
                ├── เป็นคนละอาเรย์กัน แม่ 1 ตัวอยู่ได้ที่เดียว
mothersInBag  ──┘

รายการ "เลือกแม่ส่งไปรบ" อ่านจาก mothersInBag เท่านั้น
→ แม่ในคอก **ไม่ขึ้นในกระเป๋าตั้งแต่แรก** จึงเลือกไม่ได้ ไม่ใช่เลือกแล้วโดนปฏิเสธ
```

ต้องย้ายเข้ากระเป๋าก่อน (`moveMother`) ถึงจะส่งไปรบได้ — ซึ่งเป็นการกดตั้งใจอีกหนึ่งครั้ง

กันสามชั้นซ้อนกัน:

| ชั้น | กันอะไร |
|---|---|
| **โครงข้อมูล** | สองอาเรย์แยกกัน แม่ในคอกไม่ปรากฏในรายการที่ส่งไปรบได้เลย |
| `MOTHERS_SELECTABLE_FROM_PEN = false` | `validate()` ตรึงไว้ · ตั้งเป็น `true` แล้วเซิร์ฟไม่บูต |
| `ALLOW_AUTO_RELEASE_MOTHERS = false` | ระบบ auto ปล่อยได้เฉพาะตัวลูก แม่ต้องกดเองพร้อมกล่องยืนยัน |

**และแม่เดินออกจากคอกเองไม่ได้อยู่แล้ว** — เป็น `Part` ที่ `CanCollide = false`
ขยับด้วย lerp ที่สุ่มจุดหมายในขอบเขตแปลงเท่านั้น ไม่มีทางเดินหลงไปที่เลน

> กำแพงกั้นจริง ๆ จะกันได้แค่ "ตัวละครผู้เล่นเดินข้าม" ซึ่งไม่ใช่ปัญหา —
> ปัญหาคือ "เผลอกดส่งแม่" ซึ่งกำแพงในแมพกันไม่ได้เลย

### ⚠️ ข้อกำหนดของสัตว์ที่เดินได้

| กฎ | เหตุผล |
|---|---|
| **ห้ามใช้ `Humanoid`** | คอกเต็มเลเวล 19 ตัว × 6 คน = 114 Humanoid หนักเกินไปมาก |
| ใช้ **CFrame lerp** | สุ่มจุดหมายในคอก → เดินไปหา → หยุดพัก → สุ่มใหม่ |
| **ลูปเดียวคุมทุกตัว** | `RunService.Heartbeat` ตัวเดียวใน `PenService` ไม่ใช่ลูปต่อตัว |
| **ห้ามเซฟตำแหน่งลง DataStore** | สุ่มใหม่ทุกครั้งที่เข้าเกม |

**ทำไมห้ามเซฟตำแหน่ง:** สัตว์เดินไปมาอยู่แล้ว ตำแหน่งไม่มีความหมายเชิงเกม
และการเซฟตำแหน่งของแม่ทุกตัวบวกไข่อีกเป็นหมื่นฟองจะกินโควต้า DataStore ฟรี ๆ
โดยไม่ได้อะไรกลับมา

#### ⚠️ `WANDER_SPEED` เป็น **stud ต่อวินาที** ไม่ใช่ "วินาทีต่อระยะ"

```lua
duration = ระยะทาง / WANDER_SPEED     -- ✅ เวลาแปรตามระยะจริง
```

สำคัญตรงที่คอกขยายจาก 24 → 80 studs **ถ้าเก็บเป็น "เวลาต่อระยะ" แม่จะเดินช้าเหมือนคลานทันที**
ตอนนี้แก้ขนาดคอกแล้วความเร็วคงเดิม เวลาเดินขยับตามเอง

ค่าที่ปรับได้: `WANDER_SPEED` (4) · `WANDER_PAUSE_MIN/MAX` · `WANDER_TICK`

⚠️ ที่ 4 studs/วิ แม่เดินข้ามคอกจากมุมหนึ่งไปอีกมุม (แนวทแยง 102 studs) ใช้ **≈ 25 วินาที**
ดูช้าบนกระดาษ แต่แม่เป็นของประดับที่เดินเรื่อย ๆ ไม่ใช่ของที่ต้องไปถึงไหน
ถ้าเปิด Studio แล้วรู้สึกว่านิ่งเกินไป ให้ขยับ `WANDER_SPEED` อย่างเดียว ไม่ต้องแตะอย่างอื่น

## 4. เลนรบ

- **เลนเดียว ทุกคนใช้ร่วมกัน** ทอดยาวออกไปผ่านกำแพง 9 ด่าน
- กว้าง 60 กึ่งกลางอยู่ที่ `Z = 0` ให้ตรงกับทางเดินกลางของลานคอก
- **มีกำแพงสูง 40 studs สองข้างตลอดเลน** (ที่เดียวในแมพที่มีกำแพงข้าง)
  เป็นของ server ทุกคนเห็นเหมือนกัน

### ⚠️ กำแพงข้างเลนต้องเดินเป็นขั้นตรงห้องบอส

ห้องบอสกว้าง 80 แต่เลนกว้าง 60 → **ห้องบอสล้นออกข้างเลน**
ถ้าลากกำแพงเป็นเส้นตรงยาวเส้นเดียว กำแพงจะพาดผ่ากลางห้องบอส

`MapBuilder.buildBattleLane()` จึงสร้างกำแพงเป็น**ท่อน ๆ ตามด่าน** แล้วผายออก (jog)
ตรงช่วงที่ห้องบอสกว้างกว่าเลน · ความกว้างจริงตรงจุด X ใด ๆ อ่านจาก
`Config.getLaneHalfWidthAt(x)` — **ห้ามคำนวณเอง**

### จุดปล่อยทหาร

อยู่ที่ **ต้นเลน** (`X = +128`) — ทหารโผล่ที่นั่นเลย **ไม่ต้องเดินมาจากคอก**

ตัดงานวาดทหารเดินข้ามลานทิ้งทั้งหมด ซึ่งเป็นงานที่ไม่มีใครได้ประโยชน์:
ผู้เล่นสนใจว่าทหารไปชนกำแพงเมื่อไหร่ ไม่ได้สนใจว่ามันเดินออกจากคอกยังไง

### เส้นบอกรอยต่อด่าน

`StageMarkers` บนพื้นเลนเป็น **เครื่องหมายเฉย ๆ ไม่ใช่กำแพง**
มีไว้ให้ดูออกว่าด่านไหนถึงไหนตอนเทสต์ กำแพงจริงวาดฝั่ง client

## 5. ขอบแมพ — กำแพงใส

แมพเป็น **แท่นลอย** ไม่มีอะไรรับข้างล่าง และผู้เล่นวิ่งเร็ว 32 studs/วิ (×2 จากค่าปกติ)
ยิ่งเร็วยิ่งตกขอบง่าย

**ทางที่เลือก: กำแพงใสล้อมขอบแมพทั้งหมด**

```lua
Transparency = 1     -- มองไม่เห็น ไม่บังวิว
CanCollide = true    -- ชนได้จริง
Height = 50          -- สูงกว่าที่กระโดดข้ามได้มาก
```

⚠️ **ไม่ใช้วิธี "ตกแล้วเกิดใหม่"** เพราะจะน่ารำคาญเวลากำลังฟาร์ม —
ฟาร์มอยู่ดี ๆ แล้วถูกดีดกลับจุดเกิดคือการลงโทษที่ผู้เล่นไม่ได้ทำอะไรผิด

`validate()` บังคับ `Boundary.Height > Player.JumpHeight` (7.2) —
เตี้ยกว่านั้น = กระโดดข้ามได้ ซึ่งคือสิ่งเดียวที่กำแพงใสมีไว้กัน

### รูปทรงของกรอบ

กำแพงใสล้อม 5 ชิ้น เว้นช่องกว้างเท่าเลนไว้ทางขวาให้เดินเข้าเลนรบได้:

```
        ┌──────────── North ────────────────────────────────┐
        │                                                   │
      West    ลานหญ้า + คอก        ▓  เลนรบ ═══════════►  EastUpper
        │                                                   ╪  ← ช่องเข้าเลน
        │                                                 EastLower
        └──────────── South ────────────────────────────────┘
```

`Boundary.Margin` (20) คือระยะจากขอบพื้นถึงกำแพงใส —
เว้นไว้ไม่ให้ยืนติดกำแพงแล้วรู้สึกอึดอัด

## 6. ร้านค้า

- เป็น **แผงเล็ก ๆ 2 แผง** (12 × 12 studs) วางที่ **ขอบซ้ายของลานหญ้า** ขนาบทางเดินกลาง
  **ไม่ใช่อาคารใหญ่** — ตัวแผงเป็นแค่ฉาก + จุดที่เดินไปเปิด UI ร้าน
- **ของจริงคือ UI**

### ⚠️ ไม่มีแท่นวาปแล้ว

เอาออกทั้งหมดตอนรอบ "ซื้อความเร็ว" · **ผู้เล่นเดินไปเองทุกที่**
ปัญหาระยะทางแก้ด้วย `Config.Balance.SpeedUpgrade` แทน (5 ขั้น ×1 → ×4 · ดู `docs/data-schema.md` §8.8)

**และไม่มีแท่นวาปไปรังบอสด้วย** — วาปไปรังได้เมื่อไหร่ การแย่งไข่ก็หมดความหมาย
(กติกาแย่งไข่คือกดค้าง 3 วินาทีแข่งกัน 6 คน ซึ่งต้องไปถึงที่ก่อนถึงจะแข่งได้)

| ทำอะไรได้ที่แผงร้าน | ทำได้ทุกที่ (ปุ่มติดตัว) |
|---|---|
| ขายของ · ซื้อไข่ · ซื้ออาวุธ | **อัปเกรด damage** (72 ขั้น) · **อัปเกรดความเร็ว** (5 ขั้น) |

⚠️ **อัปเกรดทั้งสองอย่างต้องไม่ต้องเดินมาร้าน** — ตัวคูณ damage มี 72 ขั้น
ถ้าต้องเดินทุกครั้งจะน่ารำคาญมาก

**เฟสนี้ทำแค่ตัวแผง** ยังไม่ทำ UI ร้านและยังไม่ทำปุ่มอัปเกรดจริง

## 7. ความเร็ววิ่งของผู้เล่น

`Player.WalkSpeed = 32` — **×2 จากค่าเริ่มต้นของ Roblox (16)** เพราะแมพใหญ่ขึ้นมาก

ตั้งที่ **`StarterPlayer.CharacterWalkSpeed`** ใน `default.project.json`
ไม่ใช่ตั้งตอน `CharacterAdded` ด้วยเหตุผลเดียวกับ `SpawnLocation` ใน §3:
Roblox ใส่ค่าให้ตั้งแต่ตอนสร้าง Humanoid = ไม่มีจังหวะที่วิ่งช้าแล้วค่อยเร็วขึ้น
และไม่ต้องจำว่าต้องตั้งซ้ำทุกครั้งที่ตาย

⚠️ `Main.server.lua` **เช็คซ้ำตอนบูต** ว่าตรงกับ `Config.MapDimensions.Player.WalkSpeed`
เพราะค่านี้แก้จาก Studio ทับไฟล์ได้ และถ้าไม่ตรง
**ตัวเลขเวลาเดินทุกตัวที่ใช้ประเมินขนาดแมพจะผิดหมดโดยไม่มีใครรู้**

### ซื้อความเร็วเพิ่มได้ถึง ×4

32 เป็นแค่ **ความเร็วฐาน** · ผู้เล่นซื้อเพิ่มได้ 5 ขั้นถึง **128 studs/วิ**
(`Config.Balance.SpeedUpgrade` · ที่มาและตารางเต็มอยู่ใน `docs/data-schema.md` §8.8)

| ขั้น | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| ความเร็ว | 32 | 61 | 80 | 97 | 113 | 128 |
| คอก → รังบอส 1 | 10.8 วิ | 5.7 | 4.3 | 3.6 | 3.1 | 2.7 |
| ไป-กลับ รังบอส 9 | 98 วิ | 52 | 39 | 32 | 28 | 25 |

### ⚠️⚠️ ความเร็วสูงสุดเป็นตัวตั้งของความหนากำแพงทุกชนิด

ที่ 128 studs/วิ บน 60 fps ตัวละครขยับ **2.13 stud ต่อเฟรม** —
กำแพงที่บางกว่านั้นถูก **ข้ามไปทั้งชิ้นระหว่างสองเฟรมโดยไม่มีการชนเกิดขึ้นเลย**

```
ความหนาขั้นต่ำ = ความเร็วสูงสุด ÷ 60 × 2 = 4.27 studs   (Config.getMinWallThickness)
```

| กำแพง | ก่อน | หลัง |
|---|---:|---:|
| กำแพงกั้นด่าน (client) | 5 | 5 |
| กำแพงข้างเลน | 3.2 | **5** |
| กำแพงใสขอบแมพ | 2 | **5** |
| รั้วคอก | — | **ยกเว้น** (`CanCollide = false` · ดู §3) |

`validate()` บังคับทั้งสี่ตัว **ขึ้นความเร็วแล้วลืมเพิ่มความหนา = เซิร์ฟไม่บูต**

⚠️ กำแพงใสขอบแมพเป็นตัวที่ทะลุแล้วเจ็บที่สุด เพราะข้างหลังไม่มีพื้น
⚠️ **รั้วคอกไม่อยู่ในกฎนี้** เพราะ `CanCollide = false` — กฎมีไว้กับกำแพงที่ต้อง *หยุด* ผู้เล่น

เวลาวิ่งที่ค่าปัจจุบันให้ (ที่ `Player.WalkSpeed` = 32 studs/วินาที):

| เส้นทาง | ระยะ | เวลา |
|---|---:|---:|
| **คอกไกลสุด → รังบอสด่าน 1** | **346** | **10.8 วิ** |
| จุดเกิด → แผงร้านค้า | 154 | 4.8 วิ |
| จุดเกิด → ต้นเลนรบ | 128 | 4.0 วิ |
| ต้นเลน → รังบอสด่าน 1 | 130 | 4.1 วิ |
| ข้ามหนึ่งด่าน | 180 | 5.6 วิ |
| ต้นเลน → รังบอสด่าน 9 | 1,570 | 49.1 วิ |
| ขอบซ้ายสุด → ขอบขวาสุด | 1,968 | 1.0 นาที |

⚠️ เป็นเวลา "วิ่งตรงไม่หยุด" ของจริงจะช้ากว่านี้เพราะมีเลี้ยว มีกระโดด มีหยุดดูของ

### ⚠️ ยามขนาดแมพช่วงเริ่มเกม

เทสต์ใน `tests/config.spec.luau` บังคับว่า **วิ่งจากคอกถึงรังบอสด่าน 1 ต้องไม่เกิน 15 วินาที**

นานกว่านั้น = แมพใหญ่เกินไปสำหรับช่วงที่ยังไม่มีอะไรทำระหว่างทาง
ตอนนี้อยู่ที่ 10.8 วิ **มีระยะเผื่อ 4.2 วิ**

ถ้าจะย่อแมพ ตัวที่กระทบมากสุดคือ `Lane.LengthPerStage` (180)
ลดเหลือ 120 จะได้เลนยาว 1,080 และสุดแมพเหลือราว 43 วินาที

ส่วนขนาดของ Part จริง ๆ ใช้ `vec3` (มีความสูง) เช่น `ReleasePadSize` · `SignSize` · `SpawnPadSize`

### ฟังก์ชันหาพิกัด — ห้ามคำนวณเอง

## 10. เปิดดูใน Studio ยังไง

### ⚠️ แมพ **ไม่ขึ้นในโหมด edit** ต้องกด Play

`MapBuilder` generate ทุกอย่างตอน **server start** ดังนั้น:

| โหมด | เห็นอะไร |
|---|---|
| **edit** (เพิ่งเปิด place) | **ว่างเปล่า ไม่มีพื้นเลย** — Workspace ไม่มีอะไรนอกจากกล้อง · ถูกต้องแล้ว |
| **Play / Run** | แมพโผล่ครบทุกโซนใน `Workspace.Map` |

ไม่ใช่บั๊ก — เป็นผลโดยตรงของกฎ "แมพสร้างจากสคริปต์ ไม่ปั้นมือ"
ถ้าอยากเห็นตัวเลขโดยไม่ต้องเปิด Studio ใช้ `luau tools/dump-map.luau` (§8)

⚠️ **ตัวละครถูกกันไม่ให้เกิดจนกว่าแมพจะสร้างเสร็จ** (`Players.CharacterAutoLoads = false`
แล้วเปิดคืนหลัง build) ไม่งั้นจะโผล่มาตอนโลกยังว่างแล้วร่วงลงเหวทันที

### ⚠️ กด Play แล้วเห็น "ท้องฟ้าว่างเปล่า" — อ่านตรงนี้

อาการ: กด Play แล้ว **ไม่มีทั้งพื้นและตัวละคร** เห็นแต่ท้องฟ้า

แปลว่า `Config.validate()` ล้ม เพราะมันอยู่**ก่อน** `MapBuilder.build()` ในลำดับบูต
พอมันล้ม สคริปต์หยุดทั้งตัว → ไม่มีใครเรียก build แมพ → ไม่มีพื้น
และ `Players.CharacterAutoLoads` ยังค้างเป็น `false` อยู่ → ไม่มีใครเกิดด้วย
**สองอย่างนี้มาจากสาเหตุเดียวกันเสมอ** ดูข้อความจริงได้ใน Output (มีป้ายกรอบให้แล้ว)

ตั้งใจให้ fail แบบนี้ — config พังแล้วไม่ควรให้ใครเข้าไปเล่น

#### ⚠️⚠️ เคยเกิดจริง: อ่าน `.Z` จากค่าที่เป็น `Vector2`

`validate()` เคยวนตรวจทุกค่าใน `MapDimensions` ด้วย `value.Z ~= nil`
เพื่อแยกว่าค่านั้นเป็น vec2 (ผังบนพื้น) หรือ vec3 (ขนาด Part)

| | อ่าน `.Z` จาก `Vector2` แล้วได้อะไร |
|---|---|
| **ใน Roblox** | `Vector2` เป็น **userdata** → **error ทันที** `Z is not a valid member of Vector2` |
| **ใน luau CLI** | fallback เป็น table ธรรมดา → คืน `nil` เงียบ ๆ |

→ เทสต์ผ่านครบ แต่เซิร์ฟจริง**ไม่บูต** และอาการที่เห็นคือท้องฟ้าว่างเปล่า

**แก้ถาวรแล้วสองชั้น:**
1. `validate()` ใช้ `Config.getOptionalZ()` (ห่อ pcall) แทนการอ่าน `.Z` ตรง ๆ
2. **fallback นอก Roblox ถูกทำให้ error เหมือน userdata จริง** (`strictVector` ใน `Config.lua`)
   → ความผิดแบบนี้จะถูกจับตั้งแต่ `luau tests/run.luau` ไม่ต้องรอเปิด Studio

⚠️ **กฎที่ได้มา: fallback ต้องเข้มเท่าของจริง ไม่ใช่แค่หน้าตาเหมือน**
fallback ที่ *ผ่อนปรนกว่า* ของจริง = เทสต์บอกว่าผ่านทั้งที่เกมพัง ซึ่งแย่กว่าไม่มีเทสต์

เทสต์อัตโนมัติตรวจได้แค่ตัวเลขใน Config (โซนไม่ทับกัน · รังอยู่หลังกำแพง · ผังคอกพอดีผู้เล่น ·
จุดเกิดอยู่บนพื้น · เวลาวิ่งถึงด่าน 1) ส่วนที่เหลือต้องเปิด Studio ดู:

**รอบขยายแมพนี้โดยเฉพาะ:**

- [ ] **ขนาดรู้สึกยังไง** — วิ่งจากคอกไปรังบอสด่าน 1 (ควรราว 11 วิ) ไกลไปหรือกำลังดี
- [ ] **กำแพงใสกันตกได้จริง** ลองวิ่งชนขอบทุกด้าน + กระโดดตรงขอบ ต้องไม่หลุด
- [ ] **ช่องเข้าเลนรบไม่ถูกกำแพงใสปิด** เดินจากลานเข้าเลนได้ลื่น
- [ ] **กำแพงข้างเลนไม่พาดผ่ากลางห้องบอส** (จุดที่ผายออก — ดู §4)

      กำแพงข้างเลน · รั้วคอก · กำแพงกั้นด่าน (ตั้งด้วย `Humanoid.WalkSpeed = 128` ใน command bar)
