# เช็คลิสต์ทดสอบ UI ใน Studio (UI-1 · UI-2 · UI-3 · UI-4 · UI-5)

> รวม "สิ่งที่ต้องทดสอบใน Studio" ของ UI-1, UI-2 (รวมรอบปรับตำแหน่ง + ขายเป็นชุด), UI-3, UI-4 และ UI-5 (ร้านค้า Robux) ไว้ที่เดียว
> **เรียงตามทางเดินจริงในเกม**: เกิดที่คอก → หน้าจอ/กระเป๋า → ป้ายหน้าคอก → ร้านหลังแมพ → ปากเลน (ป้ายดาเมจ) → แท่นอัญเชิญ
> เทสต์อัตโนมัติ (`python3 tools/check-all.py`) ตรวจได้แค่ตัวเลข/ลอจิก/การต่อสาย — **หน้าตา ตำแหน่ง ความรู้สึก ต้องดูใน Studio**
> ป้ายในวงเล็บบอกว่ามาจากรอบไหน · รายละเอียดการตัดสินใจ: `docs/ui-overhaul-plan.md`

---

## 0. เตรียมก่อนเดิน

1. `rojo serve` → Studio เชื่อม Rojo → กด **Play** (แมพไม่ขึ้นในโหมด edit)
2. Command Bar ฝั่ง **Server** (Test → Current: Server) — เรียกคำสั่ง debug ผ่านสะพานเท่านั้น (`docs/debug-commands.md`):

```lua
-- เงินพอซื้อทุกอย่าง
game.ServerStorage.EggServiceDebug:Invoke("debugSetCurrency", game.Players:GetPlayers()[1], 1000000000)
-- แม่ในกระเป๋าหลายคลาส (ใช้ทั้งร้านขายแม่และแท่นอัญเชิญ) — กดซ้ำหลายบรรทัดได้
game.ServerStorage.EggServiceDebug:Invoke("debugGrantMother", game.Players:GetPlayers()[1], 1500, "wukong", "bag")
game.ServerStorage.EggServiceDebug:Invoke("debugGrantMother", game.Players:GetPlayers()[1], 100, "monkey", "bag")
-- ผ่านด่าน 1 ไปตีด่าน 2 (ส่งแม่ไปรบได้ตั้งแต่ด่าน 2 — ด่าน 1 ไม่มีศัตรู)
game.ServerStorage.EggServiceDebug:Invoke("debugSetStageProgress", game.Players:GetPlayers()[1], 1, 0, 0)
```

3. แม่ในคอกอย่างน้อย 2–3 ตัวให้มีกองลูก (ปุ่ม 🐾 → "สวมใส่ที่ดีที่สุด" หรือย้ายจากกระเป๋า) แล้วรอให้ผลิตสักพัก
4. ทดสอบสองเครื่อง (ข้อที่มี 👥): Test → Clients and Servers → 2 Players

## 1. เกิดที่คอก — หน้าจอหลัก (UI-1)

- [ ] เกิดที่ทางเดินหน้าคอกตัวเอง
- [ ] **Hotbar** กึ่งกลางล่าง · PC 10 ช่อง / มือถือ 5 ช่อง · ไม่ทับเลเวลมุมล่างซ้าย
- [ ] **ปุ่มกระเป๋า 🎒** อยู่ถัดปุ่มของ Roblox แถบบน **ระดับเดียวกับปุ่มแชท** (ไม่ลอยสูงกว่า) ใหญ่กว่าปุ่ม Roblox นิดหน่อย (รอบแก้ตำแหน่ง 1)
- [ ] **ยอดเงิน** มุมขวาบน **ใต้**แถบของ Roblox · ไม่ชนชื่อผู้เล่น/Robux · เลขยาวย่อตัวเอง ไม่ล้นไปทับหลอดเลือด
- [ ] เลเวลมุมล่างซ้าย: 👟 Lv. N (ฟ้า) · ⚔️ Lv. N (เขียว) ตัวเอียงขอบดำ
- [ ] ปุ่มซ้าย 🛒 ร้านค้า → หน้า "เร็วๆ นี้" · กดซ้ำ = ปิด · 📖 ดัชนี → หน้าต่างดัชนีจริง (UI-4 · §7)
- [ ] **ไม่มีปุ่ม 🛠 TEMP แล้ว** (UI-3 ลบทิ้ง) · ไม่มีแผงจัดคิวปล่อยโผล่ที่ไหนเลย
- [ ] ปุ่มขวา 🥚 / 🐾 จัตุรัส ขอบดำหนา
- [ ] 🥚 แผงไข่ที่กำลังฟัก: นับถอยหลัง · ไข่ที่ค้าง (คอก+กระเป๋าเต็ม) แยกแสดง · แถบแดง ">" ปิดแผง
- [ ] 🐾 แผงแม่ในคอก: เงิน/นาที · "ถอดออก" · "สวมใส่ที่ดีที่สุด" สลับตัวอ่อนในคอกออก (กดซ้ำไม่เปลี่ยน)
- [ ] HUD การรบ (หลอดเลือดกึ่งกลางบน + สถิติมุมขวาล่าง) **ยังไม่โชว์** ตอนยังไม่ได้อัญเชิญ
- [ ] มือถือ (Device Emulator): สถิติการรบอยู่เหนือปุ่มกระโดด · แผง 🥚/🐾 กับหลอดเลือดไม่เกยกันจนอ่านไม่ออก

## 2. กระเป๋า (UI-1 · ลบปุ่มใน UI-2/UI-3)

- [ ] เปิดจากปุ่ม 🎒 · 3 แท็บซ้าย (สัตว์เลี้ยง · ไข่ · ไอเทม) · ตาราง 5 คอลัมน์ · ค้นหามุมขวาบน
- [ ] แท็บสัตว์เลี้ยง: แม่ในคอกขึ้นก่อน ป้าย "คอก" สีเขียว · แม่ที่ล็อกมี 🔒
- [ ] เลื่อนลงเร็ว ๆ ไม่กระตุก (virtual grid) · รูปตัวละครขึ้น (มีโมเดล = รูป 3D · ไม่มี = กล่องสี)
- [ ] หน้ารายละเอียดแม่: 🔒 ล็อก / 🔓 ปลดล็อก · ย้ายเข้าคอก / ย้ายออก → กระเป๋า · คอกเต็ม = ปุ่มปิด
- [ ] **ไม่มีปุ่มขาย** (UI-2 → ร้านขายแม่) และ **ไม่มีปุ่ม "ส่งไปรบ (TEMP)"** (UI-3 → แท่นอัญเชิญ)
- [ ] แท็บไข่: สแต็คตามชนิด+น้ำหนัก · "วางลงสวนฟัก" · สวนฟักเต็ม = ปุ่มปิด
- [ ] เปิดหน้าต่างอื่น (ร้านค้า/ดัชนี) = กระเป๋าปิด (เปิดได้ทีละอัน)

## 3. ป้ายหน้าประตูคอกตัวเอง (UI-2 · รอบปรับตำแหน่ง 1)

- [ ] ยืนบนทางเดินหันหน้าเข้าประตู: **ป้ายค่าวิ่ง = ซ้ายมือ · ป้ายอัปคอก = ขวามือ** (ลองทั้งคอกแถวบนและแถวล่าง)
- [ ] ป้ายไม่ขวางประตู · ไม่ทับป้าย "คอก N" · ตัวหนังสืออ่านออก ไม่กลับด้าน
- [ ] ข้อความบนป้าย = เลเวล/ราคาของเรา · เงินไม่พอ = ราคาสีแดง · สุดทาง = MAX
- [ ] เดินใกล้ → ขึ้นปุ่ม E (มือถือ = ปุ่มให้แตะ) · กด 1 ครั้งซื้อทันที (ไม่ต้องค้าง) · ป้ายเปลี่ยนเลขทันที · toast แจ้งผล
- [ ] ซื้อค่าวิ่งแล้ววิ่งเร็วขึ้นจริง · อัปคอกแล้วความจุคอกเพิ่ม (แผง 🐾)
- [ ] 👥 **ไม่เห็นป้ายค่าวิ่ง/อัปคอกของคอกคนอื่นเลย** (ทั้งเสา แผ่น ตัวหนังสือ) · คอกที่ไม่มีเจ้าของก็ไม่เห็น · ป้าย "คอก N" ยังเห็นครบทุกคอก
- [ ] 👥 อีกเครื่องเห็นป้ายของคอกตัวเองกับเลขของตัวเอง ไม่ใช่เลขของเรา

## 4. ร้านหลังแมพ (UI-2 · รอบปรับตำแหน่ง 1 · ขายเป็นชุด)

- [ ] เดินไปผนังด้านหลัง: **2 แผงติดกันกลางผนัง** (ร้านขายแม่ฝั่ง −Z · ซื้ออาวุธฝั่ง +Z) · เดินผ่านช่องกลางระหว่างแผงได้
- [ ] ป้ายลอยสองแผงไม่ทับกันจนอ่านไม่ออก · แผง 1 ขึ้นชื่อ "ร้านขายแม่" (ไม่มีคำว่า "ซื้อไข่")
- [ ] กด E ที่เคาน์เตอร์ร้านขายแม่ → หน้าต่างขาย (ตำแหน่ง/ขนาดเดียวกับกระเป๋า)
- [ ] เห็นเฉพาะแม่ในกระเป๋า (แม่ในคอกไม่ขึ้น) · เรียงไม่ล็อกก่อน ราคาถูกก่อน · ราคาใต้การ์ด
- [ ] แม่ที่ล็อก = ทาเทา + 🔒 กดแล้วแจ้งเตือน ติ๊กไม่ได้
- [ ] ติ๊กหลายตัว → ปุ่ม "ขายที่เลือก (N ตัว · รวม ฿X)" เลขเต็มหลัก · "เลือกทั้งหมดที่ไม่ได้ล็อก" / กดอีกที = ยกเลิกทั้งหมด
- [ ] กดขาย → กล่องยืนยัน (จำนวน + ราคารวม) · **ยกเลิก** = ไม่มีอะไรหาย ที่ติ๊กยังอยู่
- [ ] ยืนยัน → **toast สรุปครั้งเดียว** "ขายแม่ N ตัว ได้ ฿X" (ไม่ใช่ toast ทีละตัว) · เงินเพิ่มเท่ายอดรวมที่เห็นในกล่องพอดี
- [ ] ขายชุดที่มีแม่ถูกล็อกจากที่อื่นระหว่างเปิดกล่อง → toast บอก "· ข้าม K ตัว"
- [ ] เดินออกห่างแผงเกิน ~20 studs → หน้าต่างปิดเอง · เปิดใหม่ = ไม่มีที่ค้างติ๊ก

## 5. ปากเลน — ป้ายดาเมจ + กำแพงข้างเลน (UI-2 · รอบปรับตำแหน่ง 1)

- [ ] ป้ายอัปดาเมจอยู่ปากเลนฝั่งลาน (ระหว่างแนวกำแพงเลนเหนือกับรั้วคอก 3) ไม่ขวางทางเข้าเลน
- [ ] กด E ซื้อดาเมจ · ติดเพดานด่าน = "เต็มแล้ว — พังด่านถัดไปเพื่อปลดล็อก"
- [ ] ยืนระหว่างป้ายค่าวิ่งคอก 3 กับป้ายดาเมจ (ห่าง ~11 studs) → **ขึ้นปุ่ม E อันเดียว** (อันที่ใกล้สุด) · ขยับแล้วสลับเอง
- [ ] **กำแพงข้างเลนทั้งสองฝั่งปากเลนเสมอแนวกำแพงใส** ไม่ยื่นเข้าลาน (ดูทั้งฝั่งคอก 3 และคอก 6)
- [ ] เดินจากลานเข้าเลนได้ลื่น ไม่ติดมุมกำแพง

## 6. แท่นอัญเชิญ (UI-3)

### 6.1 ตัวแท่น

- [ ] **จานกลมเรืองแสง** (ฐานหินเทา + แกนฟ้า Neon) กลางปากเลน · มีแสงสว่างรอบแท่น · **อนุภาคลอยขึ้นช้า ๆ** · ป้ายลอย "แท่นอัญเชิญ"
- [ ] **ไม่มีแท่นสี่เหลี่ยมสีฟ้าเดิม** ("จุดปล่อยทหาร") เหลืออยู่
- [ ] เดินทับแท่นได้ (ไม่ชน ไม่สะดุด) · **ไม่บังทางเข้าเลน** · ไม่ทับกำแพงข้างเลน (แท่นจบก่อนกำแพงเริ่ม)
- [ ] ยืนระหว่างแท่นกับป้ายดาเมจ → ขึ้นปุ่ม E อันเดียว (OnePerButton) · ไม่เด้งสองอันซ้อน
- [ ] เข้าใกล้แท่น → ปุ่ม E "อัญเชิญ" · **ต้องกดค้าง ~0.5 วิ** (มีวงโหลด) · กดแตะเฉย ๆ ไม่เปิด
- [ ] มือถือ: ปุ่มกดค้างบนจอใช้ได้

### 6.2 หน้าต่าง — หัว + แท็บลูก

- [ ] หน้าต่างขึ้นตำแหน่ง/ขนาดเดียวกับกระเป๋า · แท็บซ้าย 👑 แม่ / 🐣 ลูก · พื้นน้ำเงินเข้ม · เปิดมาที่แท็บลูก
- [ ] หัว: "⏸ หยุดอยู่ · ด่านที่กำลังตี: ด่าน N · แม่ในสนามรบ X/10"
- [ ] แท็บลูกโชว์**ทุกกอง**: ชื่อ · น้ำหนัก · (สถานะ ถ้ามี) · ×จำนวน · ⚔️พลังต่อตัว
- [ ] **ผู้เล่นที่ยังไม่เคยติ๊ก** (ลำดับปล่อยว่าง) เปิดหน้าต่างครั้งแรก → **ทุกกองถูกติ๊กไว้แล้ว** เลข 1, 2, 3… เรียงพลังต่อตัวมาก → น้อย
      · เอาติ๊กออกเองได้ · ยังไม่มีอะไรถูกปล่อยจนกว่าจะกดส่งไปรบ
- [ ] ติ๊กกอง → เลข 1, 2, 3 ตามลำดับที่ติ๊ก · เอากองกลางออก → กองหลังเลื่อนเลขขึ้น
- [ ] ข้อความแนะนำ "กองที่ไม่ติ๊กจะไม่ถูกปล่อย"
- [ ] ไม่ติ๊กอะไรเลย (ทั้งสองแท็บ) → ปุ่ม "ส่งไปรบ" เป็นสีเทา กดไม่ได้
- [ ] **ติ๊กแค่ลูก → กด "⚔️ ส่งไปรบ" = ไม่มีกล่องยืนยัน** → หัวเปลี่ยนเป็น 🟢 กำลังอัญเชิญ · HUD การรบโผล่ (หลอดเลือด + สถิติ)
- [ ] **ทหาร (ภาพ) โผล่บนแท่นแล้วเดินเข้าเลน** กระจายเต็มความกว้างเลน ไม่โผล่ทะลุกำแพงข้าง
- [ ] **ปล่อยเฉพาะกองที่ติ๊ก**: ดูจำนวนในการ์ด — กองที่ติ๊กลดลง · กองที่ไม่ติ๊กไม่ลด (ผลิตเพิ่มอย่างเดียว)
- [ ] ส่งแม่อย่างเดียว (ไม่ติ๊กลูกเลย) หรือกองที่ติ๊กหมดทุกกอง → **ไม่มีทหาร (ภาพ) เดินออกจากแท่น** · แม่ในสนามยังตีอยู่ (หลอดลด)
- [ ] ปล่อยตามลำดับ: กองเลข 1 ลดก่อนจนหมด แล้วค่อยกองเลข 2
- [ ] กองที่ติ๊กไว้แล้วปล่อยจนหมด (แม่ยังอยู่ในคอก) → **การ์ดยังอยู่ ขึ้น "รอผลิต" เลขเดิม** ไม่หายไป
- [ ] ปิดหน้าต่างแล้วเปิดใหม่ → **เห็นติ๊ก + ลำดับเดิม** ที่ส่งล่าสุด
- [ ] ปุ่ม "⏹ หยุดอัญเชิญ" โผล่เฉพาะตอนอัญเชิญอยู่ · กด → หยุดปล่อย · HUD การรบหาย · หัวกลับเป็น ⏸

### 6.3 แท็บแม่

- [ ] แม่ในคอก**ไม่ขึ้นเลย** · แม่ในกระเป๋าเรียงคลาสสูง/หนักก่อน
- [ ] แม่ที่ล็อก = ทาเทา + 🔒 กดแล้วแจ้งเตือน ติ๊กไม่ได้
- [ ] ติ๊กแม่ → เลข 1, 2, 3 · เอาออกแล้วเลื่อนเลข · **ลำดับแยกจากแท็บลูก** (สลับแท็บแล้วเลขของอีกแท็บยังอยู่)
- [ ] ข้อความบอก "ติ๊กได้อีก N ตัว" (= 10 − ในสนาม − ที่ติ๊ก)
- [ ] ติ๊กเกินที่ว่างใน roster → ไม่ติด + toast บอกว่าเหลือกี่ตัว
- [ ] กด "ส่งไปรบ" (มีแม่ติ๊ก) → **กล่องยืนยันครั้งเดียว** "ส่งแม่ N ตัว — แม่ทุกตัวจะตายถาวรทันทีที่ด่านที่กำลังตีพัง ดึงกลับไม่ได้" + บรรทัดบอกว่าลูกกี่กองจะถูกปล่อย
- [ ] **ยกเลิก → ไม่มีอะไรเกิดขึ้นเลย** (แม่ยังอยู่ในกระเป๋า · ไม่เริ่มอัญเชิญ · ที่ติ๊กยังอยู่)
- [ ] ยืนยัน → toast สรุปครั้งเดียว "ส่งแม่ N ตัวไปรบ (roster X/10)" · แม่ขึ้นบนสุดของแท็บ ป้าย **"ในสนาม"** ติ๊กไม่ได้ · เริ่มอัญเชิญ
- [ ] กระเป๋า (🎒) — แม่ที่ส่งไปหายจากกระเป๋า ช่องว่างขึ้น
- [ ] ในสนาม 5 ตัว ติ๊กเพิ่มได้แค่ 5 · roster เต็ม 10/10 → หัวแท็บเตือนแดง "roster เต็มแล้ว" · ติ๊กไม่ได้
- [ ] สถิติการรบมุมขวาล่าง "แม่ในสนามรบ X/10" ตรงกับหัวหน้าต่าง (HUD การรบไม่เปลี่ยนหน้าตาจากเดิม)
- [ ] ผู้เล่นใหม่ (ด่าน 1) → หัวแท็บแม่เตือน "ด่าน 1 ไม่มีศัตรูให้ตี — เปิดอัญเชิญให้ผ่านด่านนี้ไปก่อน" · การ์ดแม่ทาเทาทั้งหมด
- [ ] ผ่านครบทุกด่าน (`debugSetStageProgress` ด่าน 1–9 เป็น 0,0) → เตือน "ผ่านครบทุกด่านแล้ว…" · ติ๊กแม่ไม่ได้

### 6.4 ด่านพัง + auto-pause (ใช้ร่วมกับ Phase 4B)

- [ ] มีแม่ในสนาม แล้วเหลือกำแพง 1 HP (`debugSetStageProgress`, 2, 0, 1) + อัญเชิญอยู่ → ด่านพัง → popup เดียว "ได้ไข่ฟรี • เสียแม่ในสนามรบ Y ตัว" ขอบแดง · แท็บแม่ไม่มีป้าย "ในสนาม" เหลือ
- [ ] auto-pause (ตีไม่เข้า) → หัวหน้าต่างเตือนแดง "ตีไม่เข้า — หยุดปล่อยอัตโนมัติ · กดส่งไปรบเพื่อเริ่มใหม่" · กดส่งไปรบ = เริ่มใหม่
  (ในเฟสนี้เกิดยากมากในเกมจริง — ดูได้ถ้าเจอ ไม่ต้องบังคับให้เกิด)

### 6.5 ออกห่าง + ข้อมูลเดิม

- [ ] เดินออกห่างแท่นเกิน ~18 studs → หน้าต่างปิดเอง · กล่องยืนยันที่ค้างอยู่ปิดไปด้วย ไม่ส่งอะไร
- [ ] เปิดหน้าต่างอื่น (🎒/ร้านค้า) ตอนหน้าต่างอัญเชิญเปิด → อันเก่าปิด (เปิดได้ทีละอัน)
- [ ] **เซฟเก่า** (ก่อน UI-3): เปิดหน้าต่างครั้งแรกเห็นทุกกองถูกติ๊กอยู่แล้ว (ลำดับเดิมถูกต่อท้ายไว้ครบ) — ปกติ ไม่ใช่บั๊ก · เอาติ๊กออกแล้วส่ง = กองนั้นหยุดถูกปล่อย
- [ ] ออกเกม–เข้าใหม่ → ลำดับที่ติ๊กยังอยู่ (เซฟใน `releaseOrder`) · ติ๊กแม่ไม่ค้าง

## 7. ดัชนี (UI-4) — กลับมาที่หน้าจอหลัก ปุ่ม 📖 ด้านซ้าย

> เตรียม: เซฟเดิมก่อนอัปเดต (v3) ที่มีแม่หลายตัวในคอก + กระเป๋า + สนามรบ จะดีที่สุด — ดู migration ของจริง
> ล้างดัชนีทดสอบซ้ำ: `debugResetAll` (ล้างแม่ทั้งหมดด้วย)

### 7.1 migration (เซฟเก่า v3 → v4)

- [ ] เข้าเกมด้วยเซฟเก่า → โหลดผ่าน ไม่โดนเตะ (Output ไม่มี error migration)
- [ ] ดัชนีมีตัวละคร**ครบทุกตัวที่มีอยู่ตอนนี้** ทั้งในคอก · กระเป๋า · สนามรบ
- [ ] ตัวที่เคยมีแต่ขาย/ตายไปก่อนอัปเดต **ไม่ขึ้น** (ยอมรับแล้ว ไม่ใช่บั๊ก)
- [ ] ออกเกม–เข้าใหม่ → ดัชนีเหมือนเดิม (เซฟลง DataStore)

### 7.2 หน้าต่าง

- [ ] กด 📖 → หน้าต่างดัชนี (ไม่ใช่หน้า "เร็วๆ นี้") ตำแหน่ง/ขนาดเดียวกับกระเป๋า · กดซ้ำ = ปิด · เปิดหน้าต่างอื่น = ดัชนีปิด
- [ ] หัว "📖 ดัชนี" + **"เก็บแล้ว X/12"** ตรงกับจำนวนตัวละครที่เคยได้
- [ ] แท็บซ้าย 5 แท็บ **C · B · A · S · SS** (บนลงล่าง) ครบแม้ยังไม่ได้สักตัว · แต่ละแท็บ "C 2/4" ถูก · แท็บไม่ล้นคอลัมน์ (PC + มือถือ)
- [ ] ในแท็บ: 1 ช่อง = 1 ตัวละคร เรียงตาม Config (C: ลิง หมู ม้า ปลา · B: ตือโป๊ยก่าย ซัวเจ๋ง ม้าขาวมังกร · A: พระถัง ซุนหงอคง · S: กวนอิม เง็กเซียน · SS: องค์ยูไล)
- [ ] ขอบการ์ดสีตามคลาส
- [ ] ตัวที่เคยได้: รูป + ชื่อ + "คลาส X" · **ลิง = รูปโมเดลจริง** (ViewportFrame) · ตัวอื่น = กล่องสีคลาส
- [ ] ตัวที่ยังไม่เคยได้: **เงาดำ + "???"** · ลิง (ถ้ายังไม่เคยได้) = เงาโมเดลลิงสีดำทั้งตัว · ตัวอื่น = กล่องดำ + "?"
- [ ] กดการ์ดที่เคยได้ → แผงเล็ก: ชื่อ · คลาส · ×ตัวคูณ · **"ตอนนี้มี N ตัว"** (นับคอก + กระเป๋า + สนามรบ) · กดซ้ำ/✕ = ปิด
- [ ] กดการ์ดเงา → "???" + "ยังไม่เคยได้"
- [ ] ขายแม่ตัวละครหนึ่งจนหมด (ร้านขายแม่) → ดัชนียังเปิดช่องนั้น · "ตอนนี้มี 0 ตัว"
- [ ] ส่งแม่ไปรบแล้วด่านพัง (แม่ตาย) → ดัชนียังอยู่

### 7.3 จุดแดง (ได้ตัวใหม่ระหว่างเล่น)

- [ ] เข้าเกมใหม่ → **ไม่มี**จุดแดง
- [ ] ปิดดัชนีไว้ แล้วได้ตัวละครใหม่ครั้งแรก (ฟักไข่ หรือ `debugGrantMother` ตัวที่ยังไม่เคยได้) → **จุดแดงขึ้นที่ปุ่ม 📖**
- [ ] ได้ตัวละครซ้ำที่เคยได้แล้ว → ไม่ขึ้นจุด
- [ ] เปิดดัชนี → จุดแดงหาย · ตัวใหม่แสดงรูปแล้ว · ตัวเลข X/Y ขยับ
- [ ] ได้ตัวใหม่ตอนเปิดดัชนีอยู่ → การ์ดเปลี่ยนจากเงาเป็นรูปทันที · ไม่ขึ้นจุดแดง
- [ ] ออกเกม–เข้าใหม่ → จุดแดงไม่ค้าง (จำใน client เท่านั้น)

## 8. ร้านค้า Robux (UI-5) — กลับมาที่หน้าจอหลัก ปุ่ม 🛒 ด้านซ้าย

⚠️⚠️ **การซื้อจริงต้องมี productId จริงก่อน** — เลข `productId` ที่อยู่ใน `Config.lua` ตอนนี้ (`1000001..1000004`)
เป็น**เลขปลอมชั่วคราว** ใช้ทดสอบตรรกะได้ (§8.4 ข้างล่าง) แต่ `MarketplaceService:PromptProductPurchase` /
`GetProductInfo` จริงจะหา product ไม่เจอจนกว่าจะทำตามนี้ก่อน:

1. Publish place นี้ขึ้น Roblox (ต้องมี Universe/Place ID ก่อนถึงจะสร้าง Developer Product ได้)
2. ไปที่ Creator Dashboard ของเกมนี้ → Monetization → Developer Products → สร้าง **4 ตัว** (ตั้งราคาเท่าไหร่ก็ได้ เช่น 1 Robux
   ไว้ทดสอบก่อน ปรับราคาจริงทีหลังได้โดยไม่ต้องแก้โค้ด): "ไข่ตำนาน" · "พลังทะลุเพดาน" · "ความเร็วทะลุเพดาน" · "เร่งฟักไข่ทั้งหมด"
3. เอาเลข Product ID จริงที่ได้ ไปแทนที่ค่าปลอมใน `Config.lua` ที่ตำแหน่ง (ค้นหาคอมเมนต์
   `-- TODO: แทนที่ด้วย Product ID จริงจากเว็บ Roblox` เจอครบ 4 จุด): `DeveloperProducts.legendary_egg.productId`
   · `RobuxProducts.robux_damage_step.productId` · `RobuxProducts.robux_speed_step.productId` ·
   `RobuxProducts.robux_hatch_rush.productId`
4. Sync กลับเข้า Studio (`rojo serve` ยังเปิดอยู่) แล้วกด Play — ตอนนี้ `PromptProductPurchase` จะเปิดกล่องยืนยันซื้อจริง
   ของ Roblox (**ไม่เสีย Robux จริงตอนทดสอบใน Studio** — Roblox มีโหมดทดสอบซื้อในตัว Studio ให้อยู่แล้ว)
   และ `ProcessReceipt` จะถูกเรียกจริงด้วย receipt จริง (แม้จะเป็นการซื้อทดสอบก็ตาม)

### 8.1 หน้าต่าง

- [ ] กด 🛒 → หน้าต่างร้านค้า Robux จริง (ไม่ใช่หน้า "เร็วๆ นี้" เดิม) ตำแหน่ง/ขนาดเดียวกับกระเป๋า/ดัชนี ·
  กดซ้ำ = ปิด · เปิดหน้าต่างอื่น = ร้านนี้ปิด
- [ ] หัว "💎 ร้านค้า Robux" · เลื่อนเห็นการ์ดครบ 4 ใบ: ไข่ตำนาน · พลังทะลุเพดาน · ความเร็วทะลุเพดาน · เร่งฟักไข่ทั้งหมด
- [ ] ราคาแต่ละการ์ดโชว์ "💎 N" ที่ดึงมาจริงจาก `GetProductInfo` (ไม่ใช่ "💎 ..." ค้าง — ถ้าค้างแปลว่า productId ยังผิด/ปลอมอยู่)

### 8.2 ไข่ตำนาน

- [ ] กดซื้อ → กล่องยืนยันของ Roblox ขึ้น → ยืนยัน → toast/ผลลัพธ์ขึ้น (ผ่าน `EggService.grantEgg` — ดู Output)
- [ ] ไข่ตำนานฟองใหม่โผล่ในกระเป๋า 🎒 แท็บไข่ (คนละอันกับที่วางในสวนฟักอัตโนมัติ — ต้องกดวางเองเหมือนไข่ปกติทุกฟอง)
- [ ] วางลงสวนฟัก → ฟักคงที่ 1 นาที (`LEGENDARY_SECONDS`) ไม่ผูกกับด่าน → ได้ตัวละครคลาส **B ถึง SS เท่านั้น** (ไม่มี C)
  ลองหลายฟองจนเจอ SS สักครั้ง (ยืนยันว่า SS ออกได้เฉพาะไข่นี้จริง)

### 8.3 ทะลุเพดานดาเมจ / ความเร็ว

- [ ] กดซื้อ "พลังทะลุเพดาน" → การ์ดอัปเดต "Lv. Robux 1" ทันทีหลัง sync ถัดมา · ป้ายดาเมจ (UI-2 · ปากเลน) ยังโชว์ตัวคูณ
  **รวมโบนัสนี้แล้ว** (ตัวคูณสูงขึ้นทันทีแม้ `damageLevel` เงินในเกมไม่ขยับ)
- [ ] กดซื้อ "ความเร็วทะลุเพดาน" ตอนซื้อความเร็วเงินในเกมครบ 5 ขั้นแล้ว (128) → ผู้เล่นวิ่งเร็วขึ้นจริง**เกิน 128**
  (สังเกตจากความเร็วเดิน) · การ์ดโชว์ "ความเร็วจริง N" ตรงกับที่วิ่งจริง
- [ ] ซื้อความเร็วทะลุเพดานไปเรื่อย ๆ จนถึงจุดหนึ่ง → การ์ดเปลี่ยนเป็น "ถึงเพดานความปลอดภัยของแมพแล้ว" + ปุ่มซื้อถูกปิด
  (เทา กดไม่ติด) — ต้องปิด**ก่อน**ความเร็วจริงจะทะลุกำแพงที่มีอยู่ (ลองวิ่งชนกำแพงกั้นด่าน/กำแพงใสขอบแมพตอนความเร็วสูงสุด
  → ต้องยังชนปกติ **ไม่ทะลุ**)

### 8.4 เร่งฟักไข่ทั้งหมด (ทดสอบ logic ได้แม้ productId ยังปลอม — ผ่าน command bar)

```lua
-- วางไข่ลงสวนฟักสัก 2-3 ฟองก่อน (ผ่านกระเป๋า 🎒 แท็บไข่ตามปกติ) แล้วจำลองซื้อโดยไม่ต้องมี Robux จริง
game.ServerStorage.EggServiceDebug:Invoke("debugSimulateReceipt", game.Players:GetPlayers()[1], "robux_hatch_rush", "test-1")
-- เรียกซ้ำด้วย purchaseId เดิม ("test-1") → ต้องได้ "PurchaseGranted" เหมือนเดิม แต่ไม่เร่งซ้ำ (idempotent)
```

- [ ] ก่อนซื้อ: ไข่ที่กำลังฟักในแผงขวา 🥚 มีแถบเวลานับถอยหลังปกติ
- [ ] เรียก `debugSimulateReceipt` (หรือกดปุ่ม "เติบโตทั้งหมด" ในแผงไข่/การ์ด "เร่งฟักไข่ทั้งหมด" ในร้านถ้า productId จริงแล้ว)
  → ไข่ทุกฟองในสวนฟัก**เสร็จทันที** ย้ายเข้าคอก/กระเป๋าแม่เลย (ไม่ใช่แค่ตัดเวลาแล้วยังค้างรอ)
- [ ] ไม่มีไข่กำลังฟักเลย → ปุ่ม "เติบโตทั้งหมด" ในแผงไข่ (มุมขวา) และการ์ด "เร่งฟักไข่ทั้งหมด" ในร้านถูกปิดทั้งคู่ (เทา กดไม่ติด)
- [ ] ลอง `debugSimulateReceipt` ด้วย purchaseId เดิมซ้ำ → Output/ผลไม่เพิ่มแม่ซ้ำ (เช็คจำนวนแม่ก่อน/หลัง)

### 8.5 ProcessReceipt — idempotency ปลายทางจริง (ถ้าตั้ง productId จริงแล้ว)

- [ ] ซื้อของ 1 ชิ้นสำเร็จ 1 ครั้ง → ได้ของแค่ 1 ครั้ง (ไม่ได้ของซ้ำแม้ Output จะโชว์ log ว่า ProcessReceipt ถูกเรียก
  มากกว่า 1 ครั้งในบางเคส — Roblox เรียกซ้ำเองเป็นปกติ)
- [ ] ออกจากเกมทันทีหลังกดซื้อ (ก่อนเห็นผลลัพธ์) แล้วเข้าใหม่ → ของที่ซื้อไปต้องอยู่ครบ ไม่หาย
